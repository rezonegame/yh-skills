# Cover Reference Index

Load only the files needed for the chosen cover direction.

- Start with `auto-selection.md` to choose cover type, rendering style, mood, palette, and text policy.
- Read `types.md` and `visual-elements.md` for composition choices.
- Read `base-prompt.md` and `workflow/prompt-template.md` before native or hybrid generation.
- Read `workflow/reference-images.md` when the user supplies visual references.
- Read `workflow/confirm-options.md` only when a material visual choice cannot be inferred.
- Use `dimensions/` for mood, text, and font rules.
- Use `palettes/` for palette-specific guidance.
- Use `renderings/` for medium and rendering guidance.
- Use `style-presets.md` when a named preset fits the brief.
