# Illustration Reference Index

- Start with `visual-conception.md` to decide visual worth, `visual_form`, facts, and the composition contract.
- Continue with `workflow.md` for article analysis, placement, and asset planning.
- Read `story-scroll.md` only when the user explicitly requests a long-scroll story, growth path, retrospective overview, or product evolution graphic.
- Read `prompt-construction.md` before native generation.
- Use `styles.md` to select a style family and `style-presets.md` for ready combinations.
- Load one relevant file from `styles/` for detailed rendering rules.
- Load one relevant file from `palettes/` when color continuity needs explicit control.
- Keep the article's communication job, factual integrity, and series continuity above decorative novelty.
