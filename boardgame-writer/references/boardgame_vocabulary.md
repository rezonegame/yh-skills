# 桌游用语与玩家语言库

## 使用原则

桌游文章中使用玩家语言的目的是让文章"读起来像一个真正玩桌游的人写的"。不是每个词都要强行用黑话，而是在描述游戏体验时，自然地使用这些表达。

对于面向新手家长的文章，避免使用过于硬核的黑话，但"开盒""跑一局""翻牌"这类基础用语可以放心使用。

---

## 1. 通用桌游词汇

### 游戏类型
| 玩家用语 | 含义 | 用法示例 |
|---------|------|---------|
| 德式 / 欧式 | 策略为主、运气成分低的游戏 | "这是一款偏德式的家庭游戏" |
| 美式 | 主题优先、叙事感强的游戏 | "美式游戏的代入感很强" |
| 派对游戏 | 轻量级、社交互动为主 | "拿来当派对游戏绝对炸场" |
| 轻策 / 中策 / 重策 | 策略深度的分级 | "别看规则简单，其实是个轻策" |
| 合作游戏 | 全员一队对抗游戏机制 | "不分输赢，大家一起扛" |
| 推理游戏 / 社交推理 | 狼人杀类，靠推理和隐藏身份 | "喜欢推理的一定会上瘾" |
| 抽象棋 | 纯策略无主题 | "围棋就是最经典的抽象棋" |

### 游戏机制
| 玩家用语 | 含义 | 用法示例 |
|---------|------|---------|
| 工人放置 | Worker Placement，把棋子放到行动格占位 | "工放的精髓就是抢位" |
| 版图控制 | Area Control，争夺地图区域 | "版图控制游戏的紧张感没得说" |
| 牌库构筑 | Deck Building，在游戏中组建自己的牌库 | "你在游戏过程中慢慢构筑自己的牌库" |
| 抽取与推送 | Push Your Luck，翻牌试运气 | "贪心多翻一张可能全没了" |
| 板块拼放 | Tile Placement，放板块构建版图 | "卡卡颂就是板块拼放的经典" |
| 收集 / 成套收集 | Set Collection，凑齐特定组合得分 | "颜色配对就是成套收集" |
| 行动点 | Action Points，每回合有固定行动点 | "每回合3个行动点你自己分配" |
| 手牌管理 | Hand Management | "手牌管理做得好的人后半局稳赢" |

### 游戏配件
| 玩家用语 | 含义 |
|---------|------|
| 米宝 / Meeple | 人形小木块 |
| 指示物 / Token | 各种标记物 |
| 骰子 / D6/D10/D20 | 不同面数的骰子 |
| 版图 / 图板 | 主游戏板 |
| 玩家板 / 个人板 | 每个人面前的小板 |
| 卡牌 / 手牌 | Cards / Hand |
| 牌库 / 弃牌堆 | Deck / Discard Pile |

## 2. 桌上动作与状态

### 游戏流程
| 表达 | 场景 |
|------|------|
| 开盒 | 第一次拆开新游戏 |
| 摆桌 / 准备 | 把游戏配件摆好 |
| 教规则 / 讲规则 | 给新手解释怎么玩 |
| 吵规则 | 对规则理解有分歧 |
| 跑一局 / 来一把 | 玩一局游戏 |
| 再来一局 | 上瘾了 |
| "这把不算" | 找借口想重来 |
| 收桌 / 收纳 | 玩完了收拾 |

### 游戏中的感受
| 表达 | 含义 |
|------|------|
| 上头了 | 投入/情绪激动 |
| 翻车了 | 策略失败 |
| 血赚 | 这步操作太划算了 |
| 亏麻了 | 亏大了 |
| 绝杀 | 最后一刻逆转 |
| 被坑了 | 被其他玩家陷害 |
| 纠结 / 犹豫 | 面对多个选择 |
| 手心冒汗 | 紧张刺激 |
| 眼睛亮了 | 被某个东西吸引 |
| 全桌都笑了 | 社交欢乐的高光时刻 |
| 一下子安静了 | 某个重要时刻 |
| 炸了 | 出现意外/高潮 |

### 玩家角色
| 表达 | 含义 |
|------|------|
| Alpha Player | 一个人指挥全场的人（合作游戏里的问题） |
| 分析瘫痪 / AP | Analysis Paralysis，想太久不出牌 |
| 搅屎棍 | 不为了赢，专门搞乱 |
| 规则律师 | 对规则极较真的人 |
| 新手杀手 | 专欺负新手的人 |
| 安静型 / 社交型 | 不同的玩桌风格 |

## 3. 亲子/家庭场景专用

### 真实场景表达
- "吃完晚饭拿出来玩"
- "周末下午消磨时间"
- "比刷手机有意思多了"
- "孩子教我规则"（反转的趣味）
- "爸爸比孩子反应还慢"
- "孩子说了一句让全场安静的话"
- "平时不怎么说话的孩子忽然打开了话匣子"
- "大人以为简单结果栽了"
- "小孩完全没学过策略但直觉贼准"

### 家长痛点表达
- "平时不知道跟孩子聊什么"
- "除了作业就没别的话题了"
- "吃完饭各自刷手机"
- "想找个全家一起做的事"
- "孩子总是闹着要看iPad"
- "想让他少看屏幕但不知道用什么替代"

## 4. 评价与推荐用语

### 正面评价（自然表达）
- "这个设计太妙了"
- "第一局就上瘾了"
- "每次结尾都想再来一局"
- "看到这个机制我直接被打动了"
- "会让你整晚都在想"
- "不知不觉两个小时过去了"
- "朋友来家里第一个要玩的就是这个"

### 中性/坦诚评价
- "这个游戏可能不适合所有人"
- "如果你不喜欢大量阅读文字的话，这个可能不太适合你"
- "前几局可能需要适应一下"
- "规则其实不难，但教规则需要点耐心"
- "美术不是最惊艳的那种，但机制撑起来了"
- "对2人局不太友好"

### 避免的评价方式
- ❌ "这款游戏荣获20XX年XXX大奖"（堆砌奖项）
- ❌ "适合6-99岁"（空泛）
- ❌ "寓教于乐"（死亡用词）
- ❌ "锻炼了孩子的XXX能力"（功利化）
- ❌ "这是一款不可多得的佳作"（空话）
- ❌ "综合评分8.5/10"（不是我们的风格）
