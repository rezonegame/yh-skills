# 四层自检体系

写完后必须跑完整个四层质检流程。从硬性规则到活人感判断，层层递进。只有四层全部通过，文章才算达标。

## L1 硬性规则检查（自动扫描层）

**L1-1 禁用词扫描**
全文搜索以下词汇，出现则必须替换：
- "说白了" → 换成"坦率的讲"、"其实就是"
- "意味着什么" / "这意味着" → 换成"那结果会怎样呢"、"所以呢"
- "本质上" → 换成"说到底"、"其实"
- "换句话说" → 换成"你想想看"、"也就是说"
- "不可否认" → 直接删掉，换成正面陈述
- "综上所述" / "总的来说" → 换成具体的回扣句
- "首先...其次...最后" → 用自然的转场词替代
- "值得注意的是" / "不难发现" → 删掉，直接说
- "寓教于乐" → 删掉，用具体场景替代
- "锻炼了XXX能力" → 改成具体的行为观察
- "此外" / "不可或缺" / "至关重要" / "深入探讨" → AI高频水词，换成具体表达
- "赋能" / "闭环" / "抓手" → 互联网黑话，桌游文章里出现就是事故

**L1-2 禁用标点扫描**
- 冒号"：" → 用逗号替代
- 破折号"——" → 用逗号或句号替代
- 双引号""或"" → 用「」替代，或直接不加引号

**L1-3 结构性问题扫描**
- "让我们来看看..." / "接下来让我们..."
- "在当今...的时代" / "随着...的发展"
- 连续使用bullet point罗列观点（超过3个改成散文叙述）
- 大段加粗（超过2行的加粗几乎肯定是过度结构化）
- 规则说明书式连续步骤（"第一步...第二步...第三步..."超过4步）

**L1-4 桌游专属踩雷扫描**
- "适合全家" / "老少皆宜" → 改成具体场景
- "荣获XXX大奖" 单独出现 → 要么融入叙述要么删掉
- 配件清单超过3行 → 精简到跟体验相关的核心配件

**L1-5 AI句式模式扫描**（吸收自 humanizer-zh）
- **否定式排比**："这不仅仅是关于……这更是……" → 直接陈述，不用反转句式堆砌
- **三段式法则**：凡事凑齐三个形容词或三个并列项（"创新、启迪和深刻洞察"） → 砍掉一个，或用更具体的表述
- **同义词循环**：同一段里用不同的词指代同一个东西来避免重复（"这款游戏"→"该产品"→"本作"） → 不怕重复，宁可直接重复也别刻意换词
- **虚假范围跨度**："从XXX到XXX"式的假大空句型 → 删掉或改成具体说明
- **碎片化分段**：把一个完整句子切碎成两个极短段落来制造假节奏 → 合并回去。注意区分：真正的"句式断裂"是有情绪力量的短句独立成段，假的是机械切割

**通过标准**：以上五项扫描零命中（L1-5中的碎片化分段需人工判断）。

## L2 风格一致性检查（模式匹配层）

**L2-1 开头检查**
- 是否从一个具体的场景/事件/瞬间切入？（不是产品介绍开头）
- 第一句话是否让读者产生好奇或代入感？
- 有没有使用任何教科书或电商详情页式开头？

**L2-2 节奏与结构检查**
- 是否有长短句交替？
- 是否有一句话独立成段的"断裂"效果？（全文至少出现3次）
- 偏离主线的段落后面是否有扣主线句拉回来？
- 小标题用法是否符合当前作者的规则？（咕咚来了/苏微不用；陆工言/陈石然用有态度的标题）
- 有无碎片化分段？（把一个完整从句机械切成两个短段 ≠ 有力量的句式断裂）

**L2-3 口语化检查**
- 是否使用了推荐口语化词组？（全文至少出现8个不同的口语化表达）
- 有没有论述中的故意打破？
- 有没有至少一处自嘲或承认不足？

**L2-4 标点禁令二次确认**
- 全文是否完全没有冒号、破折号和双引号？

**通过标准**：L2-1全部通过，L2-2至少3/4通过，L2-3至少3/4通过，L2-4通过。

## L3 内容质量检查（深度审查层）

**L3-1 机制描写检查**
- 是否用了三层描写法（体验→机制→洞察）而不是规则书翻译？
- 读者不需要亲自玩就能"感受到"这个游戏的核心体验吗？
- 规则说明是否控制在5句以内？

**L3-2 场景代入检查**
- 有没有至少一个让读者"想象自己在玩"的具体场景？
- 场景是否足够具体（几个人、什么时候、什么环境、谁说了什么）？

**L3-3 文化升维检查**
- 有没有至少一处从游戏连接到更大的文化/哲学/教育参照物？
- 这个连接是否自然？

**L3-4 卖货隐匿检查**（如果文章有推荐/转化目标）
- 购买引导是否自然嵌入内容中？
- 全文的姿态是"我在分享好东西"还是"我在推销产品"？
- 有没有硬广告式的催促（"限时优惠""立即购买"）？

**L3-5 对立面与同理心检查**
- 在讲游戏好之前，是否有对可能疑虑的理解和承认？
- 有没有先站到读者的处境里？

**L3-6 玩家语言检查**
- 描述游戏体验时用的是玩家语言还是书面汉语？
- 有没有引用真实的试玩反馈或桌上观察？

**L3-7 文章类型专项检查**
根据文章原型做针对性检查：
- 开盒体验型 → 有没有拆盒的仪式感？配件描述是否带感受而非清单？
- 深度推荐型 → 故事切入是否自然？场景想象是否让人代入？
- 机制解读型 → 三层描写法是否完整？洞察层是否有深度？
- 亲子/教育型 → 是否避免了"寓教于乐"和能力锻炼式表述？
- 对比评测型 → 是否用了升番逻辑而非平铺罗列？

**通过标准**：L3-1和L3-2必须全部通过，L3-3至L3-7中相关项通过。

## L4 活人感终审（最终人格层）

以读者视角通读全文，回答核心问题：

**"读完这篇文章，我感觉是一个做游戏的人在认真跟我聊一款打动他的游戏，还是一个AI在给我输出产品信息？"**

**L4-1 温度感**
- 文中是否有"桌上画面感"——让人仿佛看到一张桌子、几个人、正在发生什么？
- 情绪表达是体感画面还是知识性描述？

**L4-2 独特性**
- 这篇文章是否有"只有做游戏的人才会写出来的角度"？
- 还是换一个AI也能写出差不多的东西？

**L4-3 姿态检查**
- 文章的语气是"做游戏的人在跟你聊天"？
- 有没有滑入"导师在讲课"或"电商在卖货"的姿态？

**L4-4 心流检查**
- 从头到尾读，有没有哪个地方注意力断掉了？
- 如果有，那个地方就是需要修复的节奏问题。

**通过标准**：整体感觉"这像是一个真人写的，而且是一个懂游戏的人写的"。
