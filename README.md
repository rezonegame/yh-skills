# YH Skills

This repository publishes the current `yh-*` skill family only.

## Skills

| Skill | Purpose |
| --- | --- |
| `yh-document-studio` | Document layout and export workflow for PDFs, resumes, one-pagers, white papers, portfolios, letters, reports, slides, changelogs, and landing pages. |
| `yh-humanizer` | Chinese text humanization and AI-tone removal, with content, style, rhythm, and self-review passes. |
| `yh-image-inspirer` | Visual-first image ideation, prompt engineering, reference search, posters, product imagery, board-game visuals, UI concepts, infographics, and image series. |
| `yh-local-knowledge` | Local knowledge workspace management: initialize folders, index sources, generate source maps, review candidates, and export trusted assets. |
| `yh-slides` | End-to-end presentation production for PPTX, HTML decks, visual decks, template fill, presenter mode, media import, and editable reconstruction. |
| `yh-social-visual` | Content-first social visual packages for articles, covers, carousels, WeChat, Xiaohongshu, Zhihu, Weibo, Douyin, and cross-platform adaptations. |

## Install

Clone the repository and point your agent or CLI skill loader at the repository root, or copy only the skill folder you need.

```bash
git clone https://github.com/rezonegame/yh-skills.git
```

Some skills include local reference assets. Runtime dependencies such as `node_modules`, caches, and generated bytecode are intentionally excluded.
