## 一、项目定位

### 核心属性

| 维度 | 定位 |
|------|------|
| **产品形态** | 轻量化角色扮演剧本杀（不分组的同伴教育活动） |
| **知识体系** | 中国计生协《成长之道》《沟通之道》教材 |
| **社会属性** | 公益科普项目，不作商业使用 |
| **目标受众** | 12-18岁青少年，单场 15 人，不分组 |
| **单场时长** | 50-90 分钟 |
| **年度主题** | 2026年：**防艾主题** → 2027年起拓展（科学避孕等） |
| **场景** | 青春健康项目点、学校、社区青少年活动中心 |

### 设计原则

基于设计思维方法论的认知原则和情感框架：

| 原则 | 本项目的体现 |
|------|-------------|
| **严肃娱乐** | 游戏不是消遣，是在安全环境中探讨真实议题的方法。青少年在角色中讨论性健康话题，降低了现实中的尴尬和防御心理 |
| **安全失败** | 在剧本推演中，角色可以做出"错误"选择而不承担现实后果——这正是学习的安全空间 |
| **三层次体验** | 本能=剧本悬念和角色代入感 → 行为=线索推理和组内讨论 → 反思=游戏后对自身行为的关联思考 |
| **以人为本** | 知识内容以12-18岁青少年的真实困惑为起点，不是从教材条目倒推 |

## 二、故事框架（初始意向）

### 核心设定

**世界观**：当代都市校园背景。某高中15名学生卷入一个"匿名健康话题分享"引发的连锁事件，每个人都有自己的秘密和困惑。通过一系列线索和角色互动，逐步揭示每个人面临的真实青春健康议题。

**叙事驱动力**：不是传统谋杀案件，而是"一件大家都隐约知道、但都在回避的事被挑明后如何应对"。

**核心悬念**："到底发生了什么？""那个人是谁？""如果是你，你会怎么做？"

### 角色体系（15人全量框架）

**角色分类**（每种角色2-3人，对应真实班级的人际结构）：

| 角色类型 | 人数 | 典型特征 | 携带的议题线索 |
|---------|------|---------|--------------|
| **"知道但不说话"者** | 3人 | 在关键事件中知情，因各种原因选择沉默 | 感染焦虑、亲密关系困惑 |
| **"正在经历"者** | 3人 | 自己正处于某个健康挑战中 | 防艾知识误区、检测意识 |
| **"好奇但不敢问"者** | 3人 | 有疑问但缺乏可靠信息源 | 基础性知识误区、信息获取渠道 |
| **"愿意帮忙"者** | 3人 | 其中一人有科学知识储备，试图帮助同学 | 正确的科学知识、支持方法 |
| **"害怕被知道"者** | 3人 | 与关键事件有间接关联，害怕牵连 | 污名化恐惧、求助心理 |

> 每类角色3人 × 5类 = 15人，每类内部角色有不同立场和秘密，确保每人的体验都不一样。

### 故事结构三幕

| 幕 | 时长 | 核心活动 | 知识目标 |
|----|------|---------|---------|
| **第一幕：破冰与代入** | 15-20分钟 | 角色分发、自我介绍、第一轮秘密解锁 | 建立安全感，了解基本角色关系 |
| **第二幕：线索推演** | 30-40分钟 | DM投放线索卡 → 各角色分享信息 → 组内讨论/辩论 | 在角色互动中自然接触防艾知识点 |
| **第三幕：抉择与反思** | 15-20分钟 | 每位角色做出最终选择 → 结果揭示 → 现实知识链接 | 从角色抉择映射到现实决策 |

## 三、知识内容结构

### 知识来源与加工流程

```
中国计生协教材          知识点拆解             剧本融合
《成长之道》 ────→     关键知识点提取 ────→    嵌入角色秘密和线索卡
《沟通之道》            按剧本场景重组          科学附录备查
```

### 防艾主题的知识模块（2026年）

| 知识模块 | 对应剧本中的呈现方式 |
|---------|-------------------|
| HIV基本知识（传播途径/不传播途径） | 线索卡中的"谣言vs事实"对比题 |
| 检测意识与检测途径 | 角色线中的"是否去检测"决策点 |
| 安全套知识与使用方法 | 角色线中的情景对话 |
| 感染者权益与去污名化 | 第三幕的讨论环节 |
| 沟通技巧（如何与伴侣/父母谈） | 角色互动中的示范对话 |

### 内容尺度把控

- 所有性健康知识表述以**中国计生协官方教材**为准
- 不出现露骨表述或成人化情节
- 情感线的重点在"关系"和"尊重"，不在"行为"
- 敏感议题的处理原则：**告诉知识，而不是教做法**

## 四、15人不分组的游戏机制设计

这是本项目最大的设计挑战。15人同时参与不分组的解决思路：

### 核心机制：角色轮换信息流

```
          ┌─ 角色A → 角色B → 角色C ─┐
    信息链 1                             │
          └───────────────────────────┘
          ┌─ 角色D → 角色E → 角色F ─┐
    信息链 2                             │
          └───────────────────────────┘
          ┌─ 角色G → 角色H → 角色I ─┐
    信息链 3                             │
          └───────────────────────────┘
          线索会合点（全员参与讨论）
```

- 15个角色拆成 5 条信息链（每条3人），每条链内部有独立的秘密传递关系
- 每轮 DM 发放线索时，每条链的某一个人获得关键信息
- **信息公开点**：每条链的信息需要在"全员讨论环节"分享出来——所有人都有发言机会
- 每轮讨论限定 3 人发言（不强制所有人同时在说），15 人轮换需要 5 轮即可完成全员覆盖

### 时间结构

| 阶段 | 时间 | 活动 |
|------|------|------|
| 准备 | 5分钟 | DM发放角色本，各自阅读 |
| 第一幕·破冰 | 15分钟 | 轮流自我介绍（每人1分钟，控制在15分钟） |
| 第一幕·秘密解锁 | 5分钟 | 每人获得第一个个人秘密 |
| 第二幕·第一轮线索 | 10分钟 | 3条链获得线索，3人发言分享 |
| 第二幕·第二轮线索 | 10分钟 | 另3条链获得线索，3人发言 |
| 第二幕·第三轮线索 | 10分钟 | 剩余3人发言，讨论深化 |
| 第二幕·自由讨论 | 10分钟 | 全员可以自由补充信息 |
| 第三幕·抉择 | 10分钟 | 每人填写最终决策卡 |
| 第三幕·反思 | 10分钟 | DM引导知识链接，科学附录解读 |
| **总计** | **~85分钟** | 在90分钟上限内 |

### 看词学/关键术语解释（科学附录）

`依据《成长之道》教学框架`

- 同伴教育 / Peer Education
- 安全性行为 / Safe Sex
- HIV / AIDS
- 窗口期 / Window Period
- 去污名化 / Destigmatization
- 知情同意 / Informed Consent

## 七、线下测试安排节奏

### 测试总控

| 指标 | 数据 |
|------|------|
| **测试次数** | 2轮 |

### 详细排期（8周时间线）

```
第1周    需求对接
           └→ 甲方提供《成长之道》《沟通之道》教材
           └→ 确认知识模块和尺度要求
第2周    角色体系设计 + 故事框架深化
           └→ 知识点嵌入剧本（第一版草案）
第3周    剧本初稿完成：主剧本 + 15人角色本 + 线索卡初稿
           └→ 甲方审阅 → 第一轮修改
第4周    内容修改 + 科学附录编写 + DM手册初稿
           └→ DM培训（线上，首次主持模拟）
第5周    🔴 第一轮线下测试（上海）
           └→ 招募15人目标受众
           └→ 测试重点：故事吸引力、角色代入感、时间控制
           └→ 产出：测试报告 + 修改清单
第6周    根据第一轮测试反馈修改
           └→ 知识内容深化 → 线索卡调整
第7周    🔴 第二轮线下测试（上海）
           └→ 同一批或换一批参与者
           └→ 测试重点：知识传递准确性、环节流畅度、15人参与感
           └→ 产出：测试报告 + 最终修改方案
第8周    终稿定稿
           └→ 实体配件制作 → DM二次培训（线上）
           └→ 交付验收
```

### 测试内容细分

| 轮次 | 测试重点 | 验证方法 | 成功标准 |
|------|---------|---------|---------|
| **第一轮** | 故事框架吸引力、角色代入感、15人流程可行性 | 观察+问卷+群体访谈 | 80%参与者表示"想继续玩下去" |
