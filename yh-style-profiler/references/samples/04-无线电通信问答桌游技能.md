# 学科资料 → Trivial Pursuit 式教育桌游

基于 arXiv:2603.13336 的完整可复现方法论。只要提供学科资料，
就能按此流程生成一套完整的 PNP（Print & Play）可打印桌游。

## 触发条件

用户在以下语境时触发本技能：
- "帮我把这门课的教材做成一套问答桌游"
- "用这个课程大纲生成一个 Trivial Pursuit"
- "我想把XX学科做成游戏，怎么设计？"
- 用户提供了教材/讲稿/习题并提到"做成桌游"或"游戏化复习"

## 前置依赖

本技能依赖两个技能的输出：
1. **card-layout-design** — 负责卡片排版和PNP输出（棋盘、题卡、功能牌的HTML生成）
2. **boardgame-educational-adaptation** — 当需要将现有桌游改编而非从零创建时参考

在执行本技能前，确认 card-layout-design 技能已安装。

## 8 步工作流

### Step 1：课程分析（Curriculum Analysis）

**输入**：课程大纲、教材目录

**动作**：
1. 将课程内容拆分为 **5-6 个知识模块**
2. 确保每个模块体量大致均衡
3. 额外设一个"趣味/冷知识"类别（占总题量 15-20%）

**输出**：类别清单（含名称、对应教材章节、预估题数）

**校验**：
- [ ] 每个类别可映射到具体的教材章节
- [ ] 类别数 5-6 个（棋盘6色的物理限制）
- [ ] 趣味类别有来源（学科史/课堂趣事/冷知识）

### Step 2：题目设计（Question Design）

**输入**：各知识模块的教材内容

**动作**：
1. **总量规划**：每个类别 15-50 题，总数 70-270 题
   - 小学版（8-12岁）：建议 60-90 题，三选一
   - 中学版（13-18岁）：建议 90-150 题，四选一
   - 大学版：150-270 题，四选一
2. **题目编写规则（Bloom's Taxonomy 映射）**：
   ```
   教材原文 → 提取关键陈述 → 转换结构
     ├─ 🟢 记忆级 (40%)：概念识别、定义匹配
     │  例：心脏的主要功能是？→ 泵血/过滤/消化/储存
     ├─ 🟡 理解级 (35%)：因果解释、机制说明
     │  例：为什么饭后不能剧烈运动？→ 影响消化/会胖/睡不着
     └─ 🔴 应用级 (25%)：场景应用、问题解决
         例：某人头晕乏力可能缺什么？→ 铁/钙/维C/蛋白质
   ```
3. **干扰项设计规则**：
   - 必须基于学生真实常见错误（参考错题集）
   - 不能是荒谬选项（如"因为心情不好"）
   - 所有选项长度相近，避免暗示
4. **来源追溯**：每题标注对应教材章节/页码

**输出**：结构化题目数据集（类别、题号、题干、4/3选项、正确答案）

**校验**：
- [ ] 所有题目源自提供的学科资料
- [ ] 每题有唯一正确答案
- [ ] 干扰项有迷惑性但不产生歧义
- [ ] 难度分布合理（40/35/25）

### Step 3：游戏机制设计

**输入**：类别数、题目数

**动作**：
1. 设计 **路径式棋盘**（环形或蛇形，30-40 格）
2. 分配 **6 种颜色** 对应 6 个类别
3. 标记 **6 个特殊格**（⭐或💎标识），只有这 6 个格发放颜色标记
4. 其余格上色对应类别颜色
5. 确定回合流程：掷骰→移动→抽同色题→答对继续/答错换队
6. 获胜条件：集齐 6 色标记 + 冠军挑战题

**可选变体**：
- **小学版简化**：三选一 + 图文题卡 + 9-12格棋盘 + 每格都答题
- **大学版完整**：四选一 + 文字题卡 + 30-40格 + 仅6特殊格发标记

**输出**：棋盘设计图（颜色布局、特殊格位置、路径流向）

### Step 4：功能牌设计

**论文原版（大学）**— 12张 × 9种：

| 类型 | 数量 | 效果 |
|:-----|:----:|:-----|
| 抢题 | ×2 | 在对方作答前抢走题目 |
| 跳过 | ×2 | 忽略当前题换抽一题 |
| 场外求助 | ×2 | 打电话给场外人（30秒） |
| 错误消除 | ×1 | 答错后可重答一次 |
| 查笔记 | ×1 | 查看课堂笔记3分钟 |
| 现场投票 | ×1 | 向其他队伍征询意见 |
| 偷队员 | ×1 | 从对方队借一名队员 |
| 跳队 | ×1 | 指定一队跳过一轮 |
| ✂️ 删选项 | ×1 | 移除2个错误选项（4选1→2选1） |

**小学简化版**（推荐）— 6张 × 3种：
| 类型 | 数量 | 效果 |
|:-----|:----:|:-----|
| 💡 小提示 | ×2 | 主持人移除一个错误选项 |
| 🔄 再来一次 | ×2 | 答错后可重答 |
| 🤝 全班帮帮 | ×2 | 向其他队征求答案意见30秒 |

### Step 5：课堂实施设计

**参数参考（论文标准）**：
| 参数 | 大学版 | 小学版 |
|:-----|:-------|:-------|
| 时长 | 2小时 | 30-40分钟 |
| 组队 | 4人/组+教师战队3人 | 2-3人/组+教师可选 |
| 氛围 | Ugly Sweater Day+糖果 | 节日主题+贴纸奖励 |
| 主持人 | 主讲教师 | 教师/学生代表 |
| 激励 | 附加分+手工礼物 | 奖状+小奖品 |

### Step 6：评估体系设计

**必做**（参考论文问卷）：
1. **Likert 问卷**（8-12题，1-5分）：
   - 享受度（2-3题）：是否享受？是否愿意再玩？
   - 理解度（2-3题）：是否帮助理解？
   - 整合度（2题）：是否连接了知识？
   - 动机（2题）：是否激励学习？
   - 整体评价（1题）
2. **开放题**（2题）：
   - "最喜欢什么？如何改进？"
   - "其他建议？"

**选做**（统计显著）：
3. **成绩对比**（Welch's t-test）：
   - 收集参与者和非参与者的期末成绩
   - H₀: μ参与者 = μ非参与者
   - HA: μ参与者 > μ非参与者
   - 注意：非随机分组存在自选择偏差，结论为"正相关"而非"因果"

### Step 7：试玩验证

课堂实施前必须完成：

1. **内部试玩**（设计者+1位不知情同事）
   - 检查规则漏洞、题面歧义
   - 计时：是否在预期时长内完成
2. **小规模试玩**（4-6名学生志愿者）
   - 30分钟试玩 + 5分钟口头反馈
   - 记录：题目清晰度、规则理解度、参与度
3. **修正迭代**：根据反馈调整
4. **全量实施**：正式使用 + 评估数据收集

### Step 8：PNP 输出

调用 **card-layout-design** 技能生成以下文件：

| 组件 | 格式 | 说明 |
|:-----|:-----|:-----|
| 规则说明书 | HTML(A4) | 规则+分组+准备流程 |
| 棋盘 | HTML(A4×2) | 左右拼接成A3 |
| 题卡 | HTML(A4, 9张/页) | 出血3mm, 安全区3mm |
| 功能牌 | HTML(A4) | 按稀有度排列 |
| 配件 | HTML(A4) | 标记+棋子+举牌 |
| 主持人速查表 | HTML(A4) | 全部答案 |
| 制作物料清单 | HTML(A4) | 成本+步骤 |

**打印指引**：浏览器打开→Ctrl+P→实际大小→背景图形✓→打印/另存PDF
