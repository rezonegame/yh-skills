# YH Style Profiler：像素级复刻枪手

> 来源：Hermes Agent 20 个工作流 — #11 "Write Like Me" Ghostwriter
> 核心原则：不模仿"看起来像 AI"，而是模仿"这个具体的人怎么写"

## 触发条件

用户在以下语境时触发本技能：
- "用我的风格写"
- "像我写的那样"
- "模仿我的文风"
- "用我平时说话的方式写"
- 提交写作样本后要求"按这个风格来"

## 核心架构

```
样本库 → 风格画像（7维度）→ 写作模式 → 改写引擎 → 自检偏差标注
                                                    ↓
                                              "最不像你"的句子列表
```

## 不可违反的边界

- 只分析用户提供、拥有或明确授权使用的样本；不要抓取或推断第三方私人语料。
- 风格画像只描述可观察的语言特征，不声称证明作者身份。
- 不新增样本中没有的经历、身份、关系、动机、时间线、数字、引语或来源。
- 不因追求风格匹配而改动事实；专有名词、数字、日期、引用和出处保持不变。
- 当前任务的受众、格式、事实与安全要求优先于历史画像。

## 三阶段工作流

### 第一阶段：风格画像构建（初次使用或新增样本时）

**输入**：用户提供或授权使用的写作样本（建议 3-5 篇，每篇 300-3000 字）。样本不足时明确降低置信度，不把一篇短文概括成稳定人格。

**分析维度**（自动提取并写入 `references/style-profile.json`）：

1. **句子节奏**：短句比例 vs 长句比例，平均句长，句长变化模式
2. **用词偏好**：高频词、口语化程度、术语密度、连接词模式
3. **段落结构**：开头方式（直接切入/铺垫），段落功能分配，过渡方式
4. **标点习惯**：破折号、括号、分号、引号的使用频率和模式
5. **修辞特征**：比喻频率、反问/设问、排比、对比结构
6. **语气温度**：正式/中立/亲切，第一人称使用频率，幽默感表现
7. **逻辑推进**：因果/递进/对照/并列，论证密度，信息落差

**输出**：`references/style-profile.json` + `references/style-summary.md`

### 第二阶段：风格改写（每次写作时）

**输入**：待写作的主题/素材 + 风格画像

**流程**：
1. 读取风格画像（`references/style-profile.json` 和 `references/style-summary.md`）
2. 按画像特征生成初稿
3. 逐句对照画像：检查每句是否落在画像的"合理波动区间"内

**画像特征快照（从用户样本分析得出）：**

```
句子节奏：中短句为主（70% ≤25字），长短交替，不用连续超长句
用词偏好：口语化程度中等，术语精准但不堆砌，善用"为什么"解释因果关系
段落结构：95%段落以观点/判断开篇，然后展开，不绕弯子
标点习惯：善用表格，括号补充信息，破折号偶用
修辞特征：善用对照（原版vs改编版），巧用记忆口诀，不堆砌比喻
语气温度：亲切但不腻，有自信（敢说"设计理由"），偶尔幽默
逻辑推进：密集的因果链，每一步都有"为什么"
```

### 第三阶段：偏差自检（交付前必做）

**流程**：
1. 改写完成后，运行 `scripts/self-check.py`（或手动执行以下自检清单）
2. 标出所有"最不像你"的句子
3. 逐句说明为什么不像，并给出修正方案

**自检清单**：

| 检查项 | 问题 | 排查方法 |
|--------|------|---------|
| 🎯 节奏偏离 | 是否有连续3句以上长度相近的句子？ | 朗读一遍，感受节奏 |
| 🎯 用词偏离 | 是否有你从来不会用的词（如"赋能""颠覆""深刻"）？ | 扫描全文，圈出可疑词 |
| 🎯 结构偏离 | 是否有"首先其次最后"式的机械结构？ | 看段落开头，是否自然 |
| 🎯 温度偏离 | 是否太正式/太随意？ | 对比你的样本，语气是否一致 |
| 🎯 逻辑偏离 | 是否出现了"另外""此外"这种没有推进感的连接？ | 检查段落之间的逻辑关系 |
| 🎯 废话偏离 | 是否有你从来不会写的废话（如"值得深思""引人深思"）？ | 逐句问"这句话删了影响理解吗" |
| 🎯 结论偏离 | 结尾是否突然拔高到宏观命题？ | 你的结尾习惯是收束还是提示？ |

**输出格式**：

```
📊 风格偏差报告

[最不像你的句子]
"xxxxx" — 原因：你从不用"值得深思"这种收尾，你的习惯是直接给结论

[修正建议]
改为：xxxxx

[整体评分]
风格匹配度：85% ✅（≥80% 通过）
```

## 样本库管理

首次使用或用户明确要求更新画像时，运行 `python scripts/analyze-samples.py` 分析样本并生成画像。不要静默覆盖用户正在维护的画像；必要时先复制一份带日期的版本。

默认样本路径为 `references/samples/`。新增样本由用户明确放入或授权写入；脚本不提供隐式抓取或不存在的 `add_sample()` 接口。

## 与 yh-humanizer 的关系

- **yh-humanizer**：去 AI 味（通用信号去除）
- **yh-style-profiler**：模仿个人风格（正向信号注入）
- 两者协同：先用 profiler 按用户风格生成 → 再用 humanizer 去除残留 AI 味
- 当用户只要求"去AI味"时，用 humanizer；当用户要求"像我写的"时，用 profiler
