## 一、布卢姆认知过程维度（Bloom's Revised Taxonomy）

| 层级 | 动词示例 | 课堂游戏化适配机制 |
|------|---------|-------------------|
| **记忆** | 识别、列举、回忆 | 配对消除、快问快答、记忆翻牌 |
| **理解** | 解释、分类、总结 | 概念排序、分类挑战、角色扮演演绎 |
| **应用** | 执行、实施、使用 | 情境模拟、任务卡执行、资源分配 |
| **分析** | 区分、组织、归因 | 线索推理、证据拼图、因果链构建 |
| **评价** | 检查、批判、判断 | 辩论对决、评审团打分、同伴互评 |
| **创造** | 生成、规划、构建 | 沙盒建造、叙事创作、原型设计 |

**知识维度交叉**：事实性 / 概念性 / 程序性 / 元认知

## 二、LM-GM 映射模型（Learning Mechanics — Game Mechanics）

### 核心概念
- **学习机制 (LM)**：源于教育理论的教学活动要素（任务、目标、反馈、反思等）
- **游戏机制 (GM)**：源于游戏设计的交互动力要素（任务、等级、徽章、角色扮演、代币等）
- **严肃游戏机制 (SGM)**：LM 与 GM 的桥接点——将教学实践转化为具体游戏元素的耦合节点

### 使用流程
1. 提取课程中的学习机制（LM节点）
2. 提取可用的游戏机制（GM节点）
3. 用表格描述 LM-GM 的静态映射关系
4. 构建 LM-GM 动态映射图（横轴=广度探索，纵轴=深度探索）
5. 识别产生的严肃游戏机制（SGM）

## 三、MDA 框架（Mechanics-Dynamics-Aesthetics）

```
设计者视角：Mechanics → Dynamics → Aesthetics
玩家视角：  Aesthetics → Dynamics → Mechanics
```

- **Mechanics（机制）**：规则、动作、控制——设计者直接编写的部分
- **Dynamics（动态）**：机制在玩家输入下的交互涌现——策略、时机、社交博弈
- **Aesthetics（美学）**：唤起的情感体验——设计的最终目标

### 八种美学体验（Hunicke et al.）

| 美学 | 含义 | 课堂适配举例 |
|------|------|-------------|
| **Sensation** 感知 | 强感官刺激 | 视觉精美的教具、音效反馈 |
| **Fantasy** 幻想 | 虚构世界代入 | 穿越历史场景、太空探险包装 |
| **Narrative** 叙事 | 戏剧化故事 | 侦探解谜串联知识点 |
| **Challenge** 挑战 | 竞争与克服 | 限时答题、难度递增关卡 |
| **Fellowship** 社交 | 合作与连结 | 小组协作任务、团队积分 |
| **Discovery** 探索 | 发现新事物 | 隐藏线索、知识宝藏 |
| **Expression** 表达 | 自我展现 | 创意作品展示、角色定制 |
| **Submission** 沉浸 | 消遣放松 | 节奏舒缓的收集类活动 |

## 四、Yusoff 九要素框架（严肃游戏设计清单）

1. **Capability（能力）**：认知/动作/情感三域的目标能力
2. **Instructional Content（教学内容）**：嵌入游戏的知识材料
3. **Intended Learning Outcomes（预期学习成果）**：可测量的学习目标
4. **Game Attributes（游戏属性）**：
   - 渐进学习、线性/非线性安排、注意力管理
   - 脚手架支持、技能迁移、有意义互动
   - 学习者控制权、内外在奖励、情境化学习、学习风格适配
5. **Learning Activity（学习活动）**：呈现概念→引发回应→提供反馈
6. **Reflection（反思）**：游戏中+游戏后的思考机会
7. **Games Genre（游戏类型）**：匹配学科特性选型
8. **Game Mechanics（游戏机制）**：基于学习活动和受众塑造规则
9. **Game Achievement（游戏成就）**：分数/资源/完成时间等衡量标准

## 五、七大严肃游戏机制

| 机制 | 含义 | 课堂举例 |
|------|------|---------|
| **Space 空间** | 游戏发生的场地/地图 | 教室分区、地图板、坐标网格 |
| **Time 时间** | 回合制/实时/倒计时 | 限时挑战、回合制讨论 |
| **Objects 物品** | 可操作的资源/道具 | 知识卡牌、资源代币、线索碎片 |
| **Actions 动作** | 玩家可执行的操作 | 抽卡、移动、交换、建造 |
| **Rules 规则** | 约束与流程 | 发言规则、得分条件、禁止项 |
| **Chance 运气** | 随机性元素 | 骰子、抽签、随机事件卡 |
| **Skill 技能** | 需掌握的能力门槛 | 知识储备、策略思考、手速 |

## 六、Kolb 体验学习环

```
具体体验（玩游戏）
    ↓
反思观察（讨论体验）
    ↓
抽象概念化（提炼规律）
    ↓
主动实验（再次尝试新策略）
    ↓
（循环）
```

### 课堂嵌入要点
- **具体体验**：确保学生主动参与，非旁观
- **反思观察**：游戏后留 5-8 分钟讨论环节
- **抽象概念化**：引导从游戏体验中提取学科知识
- **主动实验**：提供"第二轮"或"变体规则"机会

## 七、教学设计模型速查

### ADDIE 模型
分析(Analysis) → 设计(Design) → 开发(Development) → 实施(Implementation) → 评估(Evaluation)

### ARCS 动机模型（Keller）
- **A**ttention 注意力：用新奇/冲突/悬念抓住学生
- **R**elevance 相关性：连接学生已有经验与生活
- **C**onfidence 信心：提供可达成的小目标和正反馈
- **S**atisfaction 满意度：让学习成果可见可用

### Gagné 九事件
获取注意 → 告知目标 → 唤起旧知 → 呈现内容 → 提供指导 → 引出表现 → 提供反馈 → 评估表现 → 促进迁移

### SDT 自我决定理论
- **自主感**：选择权和控制感
- **胜任感**：适度挑战和成功体验
- **归属感**：社交连结和团队认同

### 控制-价值情绪诊断（Control-Value Theory）

学习者情绪源于两个维度的认知评估：**控制感**（我能做到吗？）和 **价值感**（这值得做吗？）。

| 情绪 | 控制感 | 价值感 | 课堂干预策略 |
|------|--------|--------|-------------|
| **享受** | 高 | 正面 | 维持现状，保持节奏 |
| **希望** | 中等 | 正面 | 保持适度挑战，给予鼓励 |
| **焦虑** | 中等 | 负面 | 降低难度、增加脚手架、分解任务 |
| **绝望** | 低 | 正/负面 | 紧急简化规则、提供即时成功体验 |
| **骄傲** | 高(内归因) | 正面 | 提供更高挑战、赋予领导角色 |
| **羞耻** | 低(内归因) | 负面 | 将失败重框架为学习、匿名化错误 |
| **无聊** | 高或低 | 无 | 增加新奇元素或提升难度 |

**六类学习情绪来源**：成就情绪 / 认知情绪（好奇、困惑）/ 社交情绪 / 话题情绪 / 审美情绪 / 技术情绪

## 八、叙事弧线设计

### 五幕结构
1. **铺陈 (Exposition)**：背景介绍、角色设定、世界建立
2. **升温 (Rising Action)**：刺激事件引发行动需求
3. **高潮 (Climax)**：核心冲突点、关键决策、事件汇聚
4. **回落 (Falling Action)**：高潮后果展现
5. **收束 (Resolution)**：世界如何因行动而改变

### 课堂映射：三段式操作化叙事
- **引子/前导 (Lore)** → 课堂破冰（为什么做这件事）
- **设定 (Setup)** → 游戏状态初始化（分组/发材料/讲规则）
- **收束 (Scoring)** → 终局评分 = 叙事语义终点（你的角色结局是什么）

### 五级主题深度
| 层级 | 描述 | 举例 |
|------|------|------|
| 抽象 | 纯规则无主题 | 四子棋、井字棋 |
| 轻度主题 | 主题可忽略 | 国际象棋 |
| 中度主题 | 部分机制与主题挂钩 | 卡坦岛、大富翁 |
| 强主题 | 机制为主题服务 | 瘟疫危机 |
| 叙事主题 | 如电影/小说般的故事线 | 传承类游戏 |

### 动作-主题耦合谱系（Action-Theme Spectrum）

游戏中玩家执行的动作与主题的结合程度分为五级。课堂游戏化至少应达到级别3（隐喻），低于3即为"披皮游戏"。

| 级别 | 类型 | 含义 | 课堂示例 |
|------|------|------|----------|
| 1 | **机械动作** | 纯规则操作，与主题无关 | 抽牌、掷骰子 |
| 2 | **关联动作** | 动作被贴上主题标签但无深层联系 | 把"抽牌"改名为"搜集线索" |
| 3 | **隐喻动作** | 唤起与主题类似的情感体验 | 限时抢答模拟考古发掘的紧迫感 |
| 4 | **模拟动作** | 物理上模拟主题过程 | 用天平称量模拟化学计量 |
| 5 | **字面动作** | 玩家真正执行主题行为 | 用显微镜观察标本并记录 |

## 九、八维无障碍设计清单

| 维度 | 核心关注点 |
|------|-----------|
| **色觉** | 不依赖颜色区分，用图标+形状辅助 |
| **视觉** | 字体够大、对比度够高、避免纯黑白 |
| **认知** | 控制信息量，匹配目标年龄段认知负荷 |
| **记忆** | 关键信息不超过 7±2 项，提供参考卡 |
| **情感** | 控制挫败感，避免过度焦虑的时间压力 |
| **物理** | 教具易拿取，动作要求与能力匹配 |
| **沟通** | 不强依赖口头表达，提供替代互动方式 |
| **代表性** | 包含多样化角色，避免刻板印象 |

## 十、闪电模式默认参数推断规则

| 参数 | 未指定时的默认策略 |
|------|-------------------|
| 分组形式 | 总人数 ÷ 5~6 人/组，向上取整 |
| 游戏类型 | 根据内容-形式对齐原则自动推荐（见下方决策树） |
| 驱动机制 | 根据目标布卢姆层级自动匹配 |
| 评分权重 | 知识掌握 40% + 过程表现 40% + 协作态度 20% |
| 布卢姆目标 | 小学中低年级→记忆/理解/应用；小学高年级→理解/应用/分析；初中→应用/分析/评价；高中→分析/评价/创造 |
| 教具限制 | 纸笔 + PPT（最低门槛配置） |
| 主题深度 | 默认"中度主题"——部分机制与主题挂钩 |

### 内容-形式对齐决策树
```
内容本身含有风险/决策/因果？
  ├── 是 → 适合"游戏"（含内在博弈结构）
  └── 否 → 内容需要反复练习/巩固？
        ├── 是 → 适合"游戏化"（积分/徽章/排行榜包装）
        └── 否 → 内容需要模拟真实场景？
              ├── 是 → 适合"模拟"
              └── 否 → 默认"游戏化"
```
