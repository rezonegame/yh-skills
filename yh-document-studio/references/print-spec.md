## 1. 浏览器打印能力边界（关键）

用户的实际 PDF 导出链路是 **HTML → 浏览器(Chrome/Edge) Ctrl+P → 另存为 PDF**（weasyprint 在用户机器装不上，缺 GTK 库）。因此印刷标准要按浏览器能做的来：

| 印刷要求 | 浏览器打印 | 说明 |
|---------|-----------|------|
| **出血 3mm** | ✅ 能 | `@page { margin: 0 }` + body 背景溢出。需打印对话框选"无边距" |
| **安全区 5mm** | ✅ 能 | body padding 留 5-8mm，内容不靠纸边 |
| **裁切线** | ⚠️ 半能 | CSS `@page` margin-box 伪元素画 4 角十字标；部分浏览器不支持 `@page` margin-box，退化为无标记 |
| **300 DPI** | ✅ 满足 | 矢量 HTML + 高清图（≥300DPI 源图），打印分辨率由打印机定 |
| **CMYK 色彩** | ❌ 做不到 | 浏览器只输出 RGB。送专业印厂时其 RIP 会转 CMYK，鲜艳 RGB 蓝/绿会发暗 |
| **PDF/X-4 规范** | ❌ 做不到 | Chrome 导出普通 PDF，非 PDF/X。专业印厂可能拒收，或接受后自转 |

**真相**：浏览器打印产出的 PDF，对**本地打印店、办公打印机、快印店**完全够用。对**专业印刷厂（画册、大批量、潘通专色）**可能不达标，需后处理（见第 4 节）。

## 2. 印刷档三档定义

| 档位 | 用途 | 行为 | 是否注入 print-mode.css |
|------|------|------|------------------------|
| **屏幕版**（默认） | 屏幕/邮件/网盘阅读 | 不注入，= 原 kami 行为 | 否 |
| **印刷版（本地）** | 本地/办公/快印店 | 注入 `assets/print/print-mode.css`：出血 + 安全区 + 裁切线 | 是 |
| **印刷版（专业）** | 专业印厂 | 印刷版（本地）基础上，提示用户读本文第 4 节做 CMYK/PDF-X 后处理 | 是 + 提示 |

## 3. 印刷版（本地）操作步骤

1. 在 SKILL 的「Step 4.x 导出档位」选「印刷版（本地）」或「印刷版（专业）」。
2. `inject-override.py --print` 把 `print-mode.css` 注入产物 HTML 的 `<head>`。
3. 浏览器打开产物 HTML。
4. **Ctrl+P 打开打印对话框，手动设置**：
   - 目标：另存为 PDF
   - 纸张：A4（或目标尺寸）
   - 边距：**无**（让 `@page margin:0` 生效）
   - **取消勾选"页眉和页脚"**（否则浏览器会加自己的页眉页脚，破坏出血）
   - 背景：**勾选"背景图形"**（否则 `@page`/body 背景色不打印）
5. 另存为 PDF。

> 印刷档水印（`@media screen` 的 `body::before`）只在屏幕显示提示，打印时不出现。

## 4. 印刷版（专业）后处理（可选）

浏览器打印得到的 PDF 是 RGB 普通PDF。送专业印厂前，可能需要转 CMYK + PDF/X。**本技能不自动做这一步**（工具链重、各印厂要求不同），只在下面给出可选路径：

### 4.1 GhostScript 转 PDF/X（命令行，免费）

```bash
# 先确保有 CMYK ICC 配置文件（如 JapanColor2001 Coated.icc / FOGRA39.icc）
gs -dNOPAUSE -dBATCH -sDEVICE=pdfwrite \
   -dPDFSETTINGS=/prepress \
   -sColorConversionStrategy=CMYK \
   -sProcessColorModel=DeviceCMYK \
   -sOutputFile=output-pdx.pdf input.pdf
```

> 注意：GhostScript 的 PDF/X 转换不产生完全合规的 PDF/X-4，但多数印厂接受。严格合规需 Adobe Acrobat 或 Affinity。

### 4.2 专业工具建议

- **Adobe Acrobat Pro**：Preflight → 转 PDF/X-4，最合规
- **Affinity Publisher / Designer**：导入 PDF，导出时设 PDF/X-4 + CMYK
- **印厂直接收 RGB PDF**：很多印厂的 RIP 自己转，问印厂是否接受

### 4.3 鲜艳色预警

设计时避免：
- 纯蓝 `#0000FF`、纯绿 `#00FF00`、饱和青 —— 转 CMYK 会明显发暗
- 极细线条（<0.25pt）—— 印刷可能断线
- 极小字号（<6pt）+ 反白字 —— 套印偏差会糊

## 5. 印刷生产检查清单（抽取自 print-design）

### 设计阶段
- [ ] 确认最终裁切尺寸（+3mm 出血每边）
- [ ] 建立网格系统
- [ ] 定义字号层级
- [ ] 设定页边距和安全区（5mm）

### 印前阶段（浏览器打印路径，部分不适用）
- [ ] 嵌入所有图片（HTML 本就是单文件）
- [ ] 检查图片分辨率（≥300DPI）
- [ ] 安全区内无关键内容

### 输出阶段
- [x] 浏览器打印为 PDF（本技能主路径）
- [ ] （专业）转 CMYK
- [ ] （专业）转 PDF/X-4

### 打样阶段
- [ ] 数字打样 review
- [ ] 检查色彩准确度
- [ ] 验证裁切和出血
- [ ] 校对全部文字

## 7. 常见错误（抽取自 print-design）

| 错误 | 后果 | 解决 |
|------|------|------|
| **RGB 模式** | 印刷偏色、发暗 | 送专业印厂前转 CMYK（第 4 节） |
| **低分辨率图** | 像素化、模糊 | 源图 ≥300DPI |
| **无出血** | 裁切后露白边 | 用 print-mode.css 的 `@page margin:0` |
| **忽视安全区** | 关键内容被裁 | body padding ≥5mm |
| **忽视打印对话框设置** | 浏览器加页眉页脚/边距破坏版式 | 关页眉页脚 + 选无边距 + 开背景图形 |
| **无打样** | 昂贵错误 | 印前必打样 |
