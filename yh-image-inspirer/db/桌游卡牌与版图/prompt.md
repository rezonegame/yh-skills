适合任务：桌游卡牌正面、卡牌合集、游戏版图、地图板、玩家面板、资源/行动面板、桌游盒面/封面、扩展包包装、组件展示、规则机制图、卡牌视觉系统
不适合任务：纯 App UI、纯商品电商海报、非游戏角色立绘、无规则结构的氛围插画、纯摄影写真
可作为主库：最终交付物是桌游卡牌、版图、实体组件、玩家板、桌游盒面/封面、规则帮助卡或桌游视觉系统
可作为辅助库：为人物角色、插画、UI、信息图、海报、电商展示补充桌游组件语言和规则层级
常见交叉库：人物与角色、UI与界面、图表与信息可视化、海报与排版、插画与艺术、商品与电商、场景与叙事
必要槽位：组件类型、游戏题材、玩家视角、规则信息层级、比例/尺寸、语言、是否印刷、是否需要系列一致性
可默认槽位：简体中文；卡牌默认正面平视；版图默认俯视；组件信息少量可读；边框和图标系统统一
必须确认槽位：用户说“卡牌”时确认牌面正面图/产品效果图/系列卡牌/合集图；用户说“版图”时确认是可玩地图、规则示意还是宣传视觉；用户说“封面/盒面”时确认盒面正面、盒子效果图、宣传封面海报或系列包装

默认比例：卡牌 2:3 或 3:4；卡牌合集 16:9 或 4:5；版图 1:1/4:3/16:9；玩家面板 4:3 或横版 16:9；盒面封面 1:1、2:3 或 3:4；扩展包横幅 16:9
默认语言：默认简体中文；除非用户要求，不主动加入英文标题或英文属性
常见误判：不要把卡牌做成普通角色插画；不要把版图做成无规则的奇幻地图；不要把玩家面板做成手机 App UI；不要把盒面封面做成普通插画或电商促销海报

## 例 900：角色职业卡牌矩阵

**来源：** 用户新增本地参考图

![case900.jpg](images/case900.jpg)

```text
生成一张桌游角色职业卡牌合集图，白色背景，4 列 x 5 行整齐排列 20 张小型角色卡。
每张卡使用统一的竖版牌面框架：顶部角色名称区，中部全身角色立绘，底部小型属性/阵营符号。
角色来自同一套奇幻/冒险桌游职业系统，包含战士、法师、游侠、盗贼、祭司、炼金术士、机械师等不同职业。
视觉风格为精致手绘插画，角色轮廓清楚，服装差异明显，配色丰富但统一。
所有卡牌尺寸、边框、留白、标题位置保持一致，像一套完整可印刷的角色卡原型。
避免：不要做成散乱贴纸；不要加入桌面透视；不要让每张卡风格漂移；不要出现难以辨认的小字。
```

**可迁移结构：** 多张角色卡统一矩阵 + 固定牌框 + 仅变化角色职业、主色和姿态。

## 使用提示

- 做“卡牌”时先读 `recipes/boardgame-card.md`，并区分牌面正面图、产品效果图、系列卡牌、合集图。
- 做“版图/地图板”时优先使用本库的例 916-929，并明确俯视正交、可玩路径、格子/节点/区域边界。
- 做“桌游封面/盒面/扩展包包装”时优先使用本库的例 930-933，并补读 `recipes/boardgame-cover.md`；默认区分盒面正面、盒子效果图、宣传封面海报和系列包装。
- 做“玩家面板/资源板/帮助卡”时结合例 915，并补读 `recipes/boardgame-ui.md` 或 `recipes/boardgame-rulebook.md`。
- 做“规则机制图”时以本库为主题辅助库，同时补读 `db/图表与信息可视化/prompt.md` 和 `recipes/infographic.md`。
- 做“宣传海报/众筹详情页/电商图”时本库提供组件语言和封面主视觉，主库仍按交付物切到 `db/海报与排版/` 或 `db/商品与电商/`。
