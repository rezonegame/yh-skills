## 视觉层级

### 3 秒法则

海报应在 3 秒内传达核心信息。测试方法：展示 3 秒后遮住，观者能否回忆主题、关键信息（时间/地点）？不能则层级需调整。

### 层级结构

| 层级 | 内容 | 视觉权重 |
|------|------|----------|
| L1 核心 | 标题、主视觉、关键信息 | 最大字号、最强对比 |
| L2 重要 | 副标题、时间地点、辅助视觉 | 标题的 50-70% |
| L3 支撑 | 详情、联系方式、次要信息 | 标题的 25-35% |
| L4 可选 | 细则、法律信息、致谢 | 标题的 15-20% |

### 字号参考（A2 海报 420×594mm）

| 层级 | 字号 | 视觉距离 |
|------|------|----------|
| 主标题 | 48-72pt（65-100mm） | 3-5m 可读 |
| 副标题 | 24-36pt（35-50mm） | 2-3m 可读 |
| 正文 | 14-18pt（20-25mm） | 1-2m 可读 |
| 注释 | 10-12pt（14-17mm） | 1m 内可读 |

层级递减公式：每级约为上一级的 50-70%。

### 视觉距离与最小字号

| 观看距离 | 最小字号 | 推荐字号 |
|----------|----------|----------|
| 1m | 14pt | 18-24pt |
| 2m | 24pt | 36-48pt |
| 3m | 36pt | 48-72pt |
| 5m+ | 48pt | 72-120pt |

## 网格系统

### 单栏网格

```
┌─────────────────────┐
│  [标题/头部]         │  ← 15-20%
├─────────────────────┤
│                     │
│  [主视觉]           │  ← 40-50%
│                     │
├─────────────────────┤
│  [详情/信息]        │  ← 30-35%
└─────────────────────┘
```

适合：信息类海报、动线清晰、易于扫描。

### 双栏网格

```
┌──────────┬──────────┐
│ [标题/   │ [主视觉] │  ← 50-60%
│  头部]   │          │
├──────────┴──────────┤
│ [详情信息]          │  ← 40-50%
└─────────────────────┘
```

适合：图文并重、活动海报、平衡布局。

### 三分法

将海报分为 3×3 网格，关键元素置于交叉点：
- 主视觉置于 4 个交叉点之一
- 标题置于上方或侧方三分线
- 详情置于下方三分区
- 创造动态平衡

### Z 型动线

适用于 LTR（从左到右）语言的自然阅读路径：

```
1 → 2 → 3
    ↓
    4 → 5 → 6
    ↓
    7 → 8 → 9
```

元素放置建议：
1. Logo/标题（左上）
2. 主视觉（右上）
3. 关键信息（左中）
4. 行动号召（右中）
5. 详情（左下）
6. 联系方式（右下）

### 经典图像布局

**上重下轻：** 主视觉占 50-60% 在上方，标题文字在下方。适合戏剧性、冲击力强的海报。

**居中对称：** 标题在上 15-20%，主视觉居中 40-50%，详情在下 30-35%。适合平衡、传统风格。

**左右分栏：** 图像与文字各占 50%。适合现代、动态风格。

## 排版规范

### 字体分类与用途

| 类型 | 特征 | 用途 | 示例 |
|------|------|------|------|
| Display | 装饰性强、粗体 | 标题 | Bebas Neue, Impact, Oswald |
| Sans-serif | 干净、现代 | 正文、信息 | Helvetica, Futura, Inter |
| Serif | 传统、优雅 | 正式活动、艺术感 | Garamond, Bodoni, Baskerville |
| Script | 手写风格 | 艺术、邀请函 | Brush Script, Pacifico |

### 字体配对原则

每张海报最多 2-3 种字体族：
- 主字体：标题（Display 或粗 Sans）
- 副字体：正文（Sans 或 Serif）
- 点缀字体：Script 或装饰体（少量使用）

经典配对：
1. Display + Sans-serif（最安全）
2. Serif + Sans-serif（优雅现代）
3. Sans-serif 粗 + Sans-serif 细（同族变体）
4. Script + Sans-serif（艺术感，正文必须可读）

### 行距规范

| 场景 | 行距倍数 |
|------|----------|
| 标题 | 1.1-1.2× 字号 |
| 正文 | 1.3-1.5× 字号 |
| 紧凑排版 | 1.2× |
| 宽松排版 | 1.6× |

### 文字对齐

- 左对齐：最易读，适合正文
- 居中对齐：适合标题、短文本
- 右对齐：少见，特殊效果
- 两端对齐：分栏，创造整洁边缘

避免：行尾断词、段落中出现"河流"（白色空隙贯穿段落）、过短或过长的行。

## 色彩策略

### 色彩心理学速查

| 色彩 | 联想 | 适用场景 | 避免场景 |
|------|------|----------|----------|
| 红 | 能量、紧迫、激情 | 促销、紧急、演唱会 | 过度使用显攻击性 |
| 蓝 | 信任、冷静、专业 | 企业、医疗、信息类 | 可能显冷淡 |
| 绿 | 自然、成长、健康 | 环保、有机、金融 | 可能显停滞 |
| 黄 | 乐观、温暖、注意 | 警示、高光、欢快活动 | 难读、视觉疲劳 |
| 橙 | 能量、热情、创意 | 青年、运动、艺术 | 过度显业余 |
| 紫 | 奢华、神秘、灵性 | 高端、艺术、宗教 | 可能显人造感 |
| 黑白 | 精致、对比 | 现代、优雅、戏剧感 | 可能显生硬 |

### 60-30-10 配色法则

- **60% 主导色**：背景、大面积区域（通常为中性色或品牌主色）
- **30% 辅助色**：重要区块、标题
- **10% 点缀色**：高光、行动号召、小面积强调

示例：60% 白色（背景）+ 30% 深蓝（区块）+ 10% 橙色（CTA）

### 配色方案

**单色系：** 同一色相的明暗变化。和谐、精致。

**类比色：** 色轮上相邻的颜色。温暖、统一。如蓝→蓝绿→绿。

**互补色：** 色轮上对角的颜色。高对比、活力。如蓝+橙。主导色占 70-80%，点缀色占 20-30%。

**三角色：** 色轮上等距三色。平衡、活力。如红+黄+蓝。主导色 60%，次色 25%，点缀 15%。

## 印刷制作规范

### 分辨率要求

| 海报尺寸 | 最低 DPI | 推荐 DPI |
|----------|----------|----------|
| A3 (297×420mm) | 300 | 300 |
| A2 (420×594mm) | 150-300 | 300 |
| A1 (594×841mm) | 150-200 | 300 |
| A0 (841×1189mm) | 150 | 200-300 |

### 色彩模式

- 印刷用 CMYK，不是 RGB
- 最终导出前转换 RGB→CMYK
- 测试色彩转换效果
- 推荐色彩配置文件：FOGRA39/51

### 文件格式

- 首选 PDF/X-4
- 大幅面可用 TIFF
- 包含出血和裁切标记

### 出血与安全区

```
┌─────────────────────────┐
│  出血 (3-5mm)           │  ← 超出裁切线
│  ┌───────────────────┐  │
│  │  裁切线            │  │  ← 最终尺寸
│  │  ┌─────────────┐  │  │
│  │  │ 安全区       │  │  │  ← 内容在此范围内
│  │  │             │  │  │
│  │  └─────────────┘  │  │
│  └───────────────────┘  │
└─────────────────────────┘
```

- 标准出血：A3-A2 为 3-5mm，A1+ 为 5-10mm
- 安全区：距裁切线 10-15mm
- 关键内容：距裁切线 15-20mm

### 纸张选择

| 纸型 | 克重 | 质感 | 适用 |
|------|------|------|------|
| 铜版纸（亮光） | 150-200gsm | 光面 | 照片、鲜艳色彩 |
| 哑粉纸 | 150-200gsm | 无反光 | 阅读、室内展示 |
| 丝光纸 | 150-200gsm | 低光泽 | 平衡质感 |
| 未涂布纸 | 170-200gsm | 自然 | 艺术感、高端 |
| 户外纸 | 180-220gsm | 耐候 | 外部、日晒雨淋 |

室内用 150-170gsm（经济、足够耐用），户外用 180-220gsm（耐候、持久）。

## 海报类型速查

| 类型 | 目标 | 设计重点 | 示例 |
|------|------|----------|------|
| 活动海报 | 宣布活动 | 日期/时间/地点突出 | 演唱会、会议、展览 |
| 促销海报 | 推销产品/服务 | 品牌识别、行动号召 | 打折、产品发布 |
| 信息海报 | 传达信息 | 清晰、可读 | 导览、说明、日程 |
| 艺术海报 | 表达创意 | 视觉冲击、艺术价值 | 画展、艺术印刷 |
| 政治海报 | 影响观点 | 信息、情感诉求 | 竞选、倡议 |

## 常见错误

| 错误 | 后果 | 解决方案 |
|------|------|----------|
| 文字过多 | 压倒性、不可读 | 精简文字，用视觉表达 |
| 层级不清 | 重点不明 | 用字号和对比建立层级 |
| 对比度低 | 难以阅读 | 测试对比度（最低 4.5:1） |
| 字号错误 | 距离远时不可读 | 按观看距离设定字号 |
| 布局拥挤 | 混乱、不专业 | 使用留白，限制元素数量 |
| 图片质量低 | 不专业 | 使用高分辨率图片（300 DPI） |
| RGB 色彩 | 印刷色偏 | 从一开始就用 CMYK 设计 |
| 信息缺失 | 令人困惑 | 使用必要信息检查清单 |
| CTA 弱 | 无人行动 | 清晰、突出的行动号召 |

## 与本 skill 其他海报资源的关系

本文件提供**底层原理**（为什么这样做），以下文件提供**上层应用**（具体怎么做）：

- `poster-artist-styles.md`：20 位大师的风格修饰词（Mondo、Olly Moss、Tyler Stout 等）
- `poster-composition-patterns.md`：构图模式库（负空间、居中对称、几何框架、层次景深等）

典型使用流程：先用本文件确定层级和网格 → 用 `poster-composition-patterns.md` 选构图 → 用 `poster-artist-styles.md` 选风格 → 用 `poster-genre-templates.md` 或案例库补充细节。
