# Output Checklists

## 目录

- 通用、文字和参考图检查
- 卡牌、电商、信息图和系列图检查
- UI、直播、字体海报和摄影专项检查

## 通用检查

- 任务类型是否明确：海报、UI、卡牌、信息图、摄影、商品图、包装、插画。
- 输出形态是否明确：正面图、效果图、详情页、首图、截图、三视图、系列图。
- 比例是否明确，或已按场景设置默认比例。
- 画面文字语言是否符合用户要求。
- 文字是否少量、清晰、可读。
- 是否写明关键避免项。
- 是否保留参考图主体识别。

## 文字可读检查

图像模型容易在大段文字中翻车。优先使用：

- 1 个主标题。
- 1 个副标题。
- 3-6 个短标签。
- 1 条短规则或短口号。

避免：

- 大段正文。
- 复杂中英混排。
- 多个小字号说明区。
- 同一画面超过 10 个文本点，除非是信息图并明确要求。

## 卡牌正面检查

- 是否明确“纯正面平视 / 平面正交 / 无透视”。
- 是否明确“不要桌面、不要手持、不要样机、不要产品摄影”。
- 是否包含：标题、主体图标、属性区、规则栏、边框。
- 属性数量是否克制，通常 4-6 个。
- 是否所有牌面信息都是中文。
- 如果是系列卡牌，是否重复统一风格约束。

## 电商海报检查

- 是否保留产品包装和名称识别。
- 是否明确海报比例：4:5、3:4、9:16 或电商详情页长图。
- 是否包含：标题、副标题、商品主体、卖点标签、购买行动区或适用场景。
- 商品是否完整展示，不裁切关键包装。
- 辅助元素是否服务产品，不喧宾夺主。

## 信息图检查

- 是否明确图表类型：流程、对比、时间线、拆解、关系图、地图。
- 模块数量是否明确，通常 3-6 个。
- 每个模块是否短标题 + 1 句短说明。
- 是否避免大段正文和拥挤布局。
- 是否指定中文可读文字和层级清晰。

## 参考图改造检查

- 明确”使用上传图片作为严格参考”。
- 列出必须保留的 3-5 个识别锚点。
- 只改用户要求改的部分。
- 避免把产品、人物、品牌替换成相似但不同的对象。

## Edit 任务检查

- 是否判断这是编辑任务，而不是重新生成任务。
- 是否明确写出 `Change` 与 `Preserve`。
- 是否把识别锚点放在修改说明之前。
- 是否约束“不要改动无关区域”。
- 是否根据任务类型指定了合适的 edit 模板（局部替换、背景替换、文案区重做等）。

## 系列图一致性检查

- 是否先锁定统一视觉系统。
- 是否明确定义了允许变化和不允许变化的变量。
- 是否每张图都重复统一约束，而不是依赖上下文继承。
- 是否在大于 5 张时先建立变量表。
- 是否避免不同张之间出现配色、边框、字体或布局漂移。

## UI 截图检查

- 是否指定具体平台（小红书/抖音/微信/X/微博/Instagram）。
- 是否指定平台专属 UI 特征（蓝勾、音乐碟、瀑布流、对话气泡等）。
- 所有中文文字是否逐字写明，禁止模型自创。
- 互动数据（点赞/评论/转发数）是否显式指定。
- UI 层级是否分层描述（顶部/主内容/互动栏/底部导航）。

## 直播界面检查

- 是否区分直播类型（电商/才艺/游戏）。
- 主播人物是否具体描述（姿态、服装、背景、灯光）。
- 覆盖层是否分层描述（顶部信息栏/弹幕区/礼物栏/商品栏）。
- 是否明确禁止 UI 元素遮挡主播面部。
- 弹幕文字是否使用中文且内容合理。

## 概念字体海报检查

- 标题文字是否精确拼写（错一个字全图报废）。
- 是否指定字重、字宽、对比度、间距等排版参数。
- 是否明确禁止：情绪板、网格、样机、说明文字、过程图。
- 配色是否控制在 4-6 色。
- 质感是否指定（丝网印刷/石版画/孔版画）。

## 街拍摄影检查

- 是否指定手机视角（手持、略俯或低角度、自然构图）。
- 是否要求 raw unedited photo look。
- 是否明确禁止：插画、动漫、CGI、棚拍灯光、漂浮物体、品牌文字、水印。
- 场景是否描述地面材质、墙面、街景等环境细节。
- 是否有纪实感而非杂志大片感。

## GPT-Image-2 专项检查

- 主体是否前置，而不是被背景与风格词埋没。
- 是否优先使用正向约束，而不是大量负面关键词。
- 有必须准确显示的文字时，是否已用引号或显式逐字文字锁定。
- 镜头参数、机位、光线是否写得具体且服务任务。
- 是否判断了该任务更适合强模板、轻模板还是非模板。
- 编辑任务是否已切换到 `Change / Preserve` 结构。

## 升级后自测检查

- 新增规则是否能在 `source-registry.md` 找到来源。
- 新增知识是否有清晰落点，而不是只写在 `evolution-log.md`。
- `upstream-gap-tracker.md` 是否更新了“已补 / 未补 / 暂不吸收”状态。
- 若某个旧方案被放弃，是否写入 `fossil-record.md`。
- 新增模板或流程是否已在 `SKILL.md` 资源地图中可被发现。
## 海报层级检验（3 秒法则）

> 来源：poster-design / flyer-design

生成前默认对齐以下问题，若有明确缺失则补进 prompt：

- **主信息 3 秒可识别**：主标题或核心视觉是否绝对主导画面？
- **视觉焦点唯一**：Level 1（最重要）信息不超过 1-2 个元素。
- **室外/交通媒介**：需显著提高对比度，减少文字量到"1 个视觉 + 1 句话"。
- **社媒手机端**：比例 4:5 或 1:1，标题字号要在拇指滑屏时可读。
- **传单近距手持**：A5/A4，可承载适中信息量，5 秒内读完核心内容。

## 印刷意图检查

> 来源：print-design

当用户明确提到"要印刷""做实物""出版""印卡牌"时，在 prompt 中追加以下约束：

**通用印刷约束：**
```
print-ready, 300 DPI equivalent resolution, CMYK-safe colors, no pure RGB neon
```

**大批量印刷（offset，500份以上）：**
```
flat color blocks preferred, minimize gradients, Pantone-safe palette
```

**桌游组件 / 卡牌（Interactive 物料）：**
```
distance-readable text, high contrast between text and background,
simple icon shapes recognizable at arm's length
```

**数字短版印刷（Digital Print，小于500份）：**
```
可保留渐变和细节, 但避免极细线条（低于0.5pt）
```

## 极简 / Zine 海报量化检查

- 负空间是否约占画面 70%-90%。
- 主体视觉集群是否约占画面 8%-25%，且只有一个主要视觉隐喻。
- 锚色是否在缩略图下仍可辨认，面积约占画布 0.8%-2.5% 或主体集群 15%-35%。
- 是否避免 `pale`、`muted`、`faded`、`pastel`、`low saturation` 等与高纯度锚色冲突的词。
- 是否保留扫描纸张、剪报、套印或印刷痕迹，而非数字光滑表面。
- 若任务不是广告，是否去掉商业标题层级、Logo 和 CTA。

## Prompt 编译器检查

- 画布、注意力结构、主体锚点、锚点处理、排版、色彩逻辑、质感、情绪/氛围和 Hard Avoids 是否都有答案。
- Prompt 是否能在删掉字段名后仍读成一幅连续、可渲染的画面。
- 主体、比例、参考图保留项和用户禁忌是否在前半段明确出现。
- 锚色是否写明色相、承载材质、功能角色和面积，而非只给色名。
- 多方案之间是否改变了至少两个设计轴，而不是只换颜色或装饰。
