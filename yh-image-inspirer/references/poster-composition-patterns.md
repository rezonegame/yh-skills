## 1. Centered Symmetrical（居中对称）

**描述：** 主体绝对居中，左右镜像平衡，制造标志性强冲击力。

**使用场景：** 英雄人物/物件、正面对抗、冥想/精神主题、最大品牌识别度

**Prompt 关键词：**
```
centered symmetrical composition, balanced mirrored layout, frontal iconic
placement, dead-center focus, perfect vertical axis symmetry
```

**示例 prompt 片段：**
```
Masked vigilante face centered perfectly in Mondo poster style, symmetrical
composition, balanced left-right elements, 3-color print: black, red, cream,
frontal iconic hero placement, vertical axis mirror symmetry
```

---

## 2. Negative Space Mastery（负空间精通）

**描述：** 战略性空白创造隐藏图像、暗示规模、或构成视觉双重含义。空白区域与填充区域同等重要。

**使用场景：** 极简设计、有神秘/隐藏主题的电影、1-3 色限制

**Prompt 关键词：**
```
negative space storytelling, empty space creates hidden image, clever use of
blank areas, visual double meaning, silhouette reveals secondary image
```

**技法变体：**

*隐藏图像：* 主体剪影内部包含完全不同的图像
```
Detective silhouette in fedora, negative space within hat and shoulders forms
city skyline in Mondo poster style, clever dual imagery, 2-color print: black
and cream, Olly Moss negative space technique
```

*通过缺失暗示：* 只展示部分，让负空间暗示其余
```
Single shark fin breaking water surface, vast negative space ocean in Mondo
poster style, minimalist threat implication, 2-color print: ocean blue and white
```

## 3. Geometric Framing（几何框架）

**描述：** 使用圆形、三角形、拱门或其他几何形状框住或包含主视觉。

**使用场景：** 组织构图、Art Deco 或年代风格、门/窗隐喻、视觉层级控制

**形状含义：**
- **圆形** → 统一、完整、循环
- **三角形** → 冲突、层级、上升、不稳定
- **拱形** → 门户、通道、哥特宏伟、阈值
- **六边形** → 技术、现代感、效率

**Prompt 关键词：**
```
geometric [circle/triangle/arch/hexagon] framing, contained within [shape],
Art Deco decorative geometry, structured compositional boundaries
```

**示例：**
```
Spaceship emerging from circular tunnel in Mondo poster style, perfect circle
geometric framing, concentric rings creating depth, 3-color print: navy, silver,
orange accent, centered radial composition, portal metaphor
```

## 4. Layered Depth（层次景深）

**描述：** 明显的前景、中景、背景三层，在平面丝网印刷美学下创造维度感。

**使用场景：** 风景主导设计、史诗规模强调、环境叙事、西部/科幻/奇幻

**Prompt 关键词：**
```
layered depth with distinct foreground/midground/background, three-plane
composition, foreground silhouette against mid-distance [element] and far
[element], dimensional layers in flat screen print
```

**层次策略：**

*深色 → 中调 → 浅色：*
```
Black twisted tree in foreground, fog-shrouded mansion in midground, pale moon
background in Mondo poster style, three distinct depth layers, 3-color print:
black, gray, cream
```

*通过尺寸创造层次：*
```
Tiny astronaut in foreground, medium rover in midground, massive planet looming
in background in Mondo poster style, layered scale progression
```

## 5. Silhouette Dominance（剪影主导）

**描述：** 主体简化为纯剪影，无内部细节——形状、姿态和轮廓讲述故事。

**使用场景：** 标志性角色识别、强调氛围而非细节、神秘感

**Prompt 关键词：**
```
pure silhouette without internal detail, filled black shape, recognizable by
outline only, no facial features shown, posture and shape tell story
```

**剪影类型：**

*角色识别（仅靠外形辨认人物）：*
```
Batman cape and cowl silhouette, no face details, pure black shape against
cream background in Mondo poster style, 2-color print
```

*环境氛围（景观/建筑剪影）：*
```
Victorian mansion pure black silhouette against blood red sunset in Mondo
poster style, no architectural details just gothic outline, 2-color print
```

*叠层剪影：*
```
Cowboy on horseback layered over desert mesa layers, all in silhouette in
Mondo poster style, overlapping black shapes, 3-color print
```

## 6. Visual Puns & Hidden Imagery（视觉双关与隐藏图像）

**描述：** 一个物件变形为另一个，或隐藏图像等待细看发现。Laurent Durieux 的专长。

**使用场景：** 有深度的剧情片、有反转的电影、提升收藏价值（发现因素）

**Prompt 关键词：**
```
visual pun where [A] doubles as [B], hidden [element] within [main subject],
clever dual-purpose composition, Laurent Durieux style visual trick
```

**技法变体：**

*物件变形：*
```
Opened briefcase transforms into city skyline in Mondo poster style, visual pun
composition, business case lid becomes building skyline, 3-color print: navy,
bronze, cream
```

*隐藏人形：*
```
Forest landscape with creature face hidden in tree line in Mondo poster style,
secondary imagery rewards inspection, mystery revealed on close viewing
```

*隐喻融合：*
```
Brain cross-section that's also a maze in Mondo poster style, mind-as-puzzle
imagery, 2-color print: pink and cream
```

## 7. Typography Integration（排版融合）

**描述：** 手绘复古字体作为构图元素，不只是文字叠加——排版参与设计。

**使用场景：** 标题简短有标志性、复古年代精准度、文字本身是视觉故事

**Prompt 关键词：**
```
bold retro typography integrated into composition, hand-drawn lettering as
design element, [Art Deco/condensed sans-serif/hand-painted] title treatment,
vintage [decade] lettering style, typography participates in visual design
```

**按年代的字体风格：**
- **1940s-50s：** 粗宽sans-serif、手绘圆润字母
- **1960s-70s：** 迷幻变形字体、宽间距
- **1980s：** 压缩无衬线、霓虹效果
- **当代 Mondo：** 凝练无衬线、复古衬线混搭

---

## 8. Border & Edge Treatments（边框与边缘处理）

**描述：** 装饰性边框作为限量版收藏感的标志。

**常用风格：**

| 边框风格 | 适用场景 | prompt 词 |
|---------|---------|----------|
| Art Deco 几何 | 1920-40s 年代片 | `Art Deco decorative border, geometric frame` |
| 手绘粗线框 | 独立/民间风 | `rough hand-drawn border, folk art frame` |
| 圆角矩形 | 现代简洁 | `simple clean border, rounded corners` |
| 无边框满版 | 强主视觉冲击 | `full bleed image, no border` |
| 复古老旧纸张 | 怀旧氛围 | `aged paper border, yellowed edges, vintage wear` |
