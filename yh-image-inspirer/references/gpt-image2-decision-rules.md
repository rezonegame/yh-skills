# GPT-Image-2 Decision Rules

本文件吸收 `yinyo-image2-prompt` 中最有价值的 GPT-Image-2 专项方法，但保持 `yh-image-inspirer` 的通用工作流定位。

## 目录

- 模型特性与任务分类
- 提问、A/B 和编辑策略
- 简化 5-Phase 流程
- 与当前 skill 的配合关系

## 1. 模型特性

- **主题前置**：核心主体放在 prompt 前 20%-30%，不要被背景、氛围、风格词埋掉。
- **正向约束优先**：优先写“要什么、保留什么、如何呈现”，少依赖冗长负面词。
- **文字加引号**：当画面中有必须准确显示的标题、标签、按钮、牌面词时，用引号包裹关键文字。
- **镜头参数是有效控制项**：焦距、光圈、机位、视角、色温不是装饰词，是真正的控制变量。
- **编辑任务必须拆分变与不变**：涉及参考图改造时，统一写成 `Change` / `Preserve`。
- **长 prompt 不是默认更好**：如果任务本质简单，优先用清晰的结构化短 prompt，而不是形容词堆叠。

## 2. 任务分类决策

### 适合强模板化

- UI 截图
- 直播界面
- 信息图
- 电商海报
- 卡牌正面
- 品牌系统视觉板
- 规则图解
- 系列图批量生成

### 适合轻模板化

- 海报
- 商品发布图
- 文档/出版物
- 玩家面板
- 封面/盒面
- 高级品牌视觉

### 适合非模板或弱模板

- 情绪型概念插画
- 单张强叙事情境图
- 诗意摄影感画面
- 风格探索型插画

## 3. 提问策略

只在缺失关键信息时提问，最多 1-3 个。

### 必问的缺口

- 输出形态不明：正面图、效果图、海报、详情页、信息图、截图、规则页
- 是否严格保留参考图识别
- 是否需要系列一致性
- 画面文字语言与必须显示文字

### 可直接补默认值

- 默认中文画面文字
- 默认按场景选择比例
- 默认减少文字量
- 用户说“卡牌”但未说明时，优先牌面正面图
- 商品参考图任务默认保留包装与品牌识别

### 什么时候不要继续追问

- 用户已经明确说“直接生成 / 不用确认”
- 用户提供的信息足够形成完整 brief
- 用户只需要灵感、案例或 prompt，而不是立即出图

## 4. A/B 策略

以下任务适合一次输出主方案 + 备选方案：

- 海报主视觉
- 品牌 campaign 图
- 商品发布图
- 系列图的第一张母版
- 概念海报

### A/B 使用规则

- `A` 保守：更强调信息清晰、结构稳定、可落地。
- `B` 探索：允许更强的构图张力、视觉比喻或风格表达。
- 不对所有任务默认启用 A/B。牌面正面、规则图、UI 截图等结构性任务，通常优先单方案稳定输出。

## 5. 编辑模式策略

以下场景优先进入 edit workflow，而不是普通生成：

- 用户上传参考图，并明确要改局部
- 用户强调“主体不要变，只换背景/风格/文案”
- 商品图、包装图、角色图要求保身份
- 卡牌、海报、详情页需要保结构重做

以下场景更适合普通生成：

- 只有口头描述，没有参考图
- 用户只想要“类似风格”，不要求保主体
- 本质是新画面创作，而不是修改既有画面

## 6. 简化 5-Phase 流程

### Phase 0: 判断任务复杂度

- 是否有参考图
- 是否必须保主体
- 是否属于强结构任务
- 是否需要系列一致性

### Phase 1: 明确交付物

- 输出形态
- 主体
- 语言
- 比例
- 关键保留项

### Phase 2: 选择工作流

- 强模板
- 轻模板
- 非模板
- edit workflow
- 系列 workflow

### Phase 3: 形成 brief

- 主视觉
- 信息层级
- 画面文字
- 统一风格
- 避免项

### Phase 4: 输出 prompt 或 prompt snapshot

- 对用户可读时，用 brief
- 对模型执行时，用结构化 prompt

### Phase 5: 生成后反馈循环

- 成功经验 -> `learning-capture-rules.md`
- 翻车点 -> `output-checklists.md`
- 来源吸收差异 -> `upstream-gap-tracker.md`

## 7. 与当前 skill 的配合关系

- 本文件不替代 `SKILL.md` 的总流程。
- 本文件只负责 GPT-Image-2 专项判断。
- 参考图编辑任务必须联动 `edit-workflows.md`。
- 模板选型仍以 `structured-templates.md` 和 `template-index.md` 为主。
