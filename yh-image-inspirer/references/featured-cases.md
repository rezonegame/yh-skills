# Featured Cases

高复用精选入口。目标不是覆盖全库，而是让未来维护者或使用者快速找到“先从哪里抄结构最值”。

## 1. 桌游卡牌与版图

- `db/桌游卡牌与版图/prompt.md`
  适合：卡牌正面、玩家面板、资源板、盒面、规则帮助卡
  先看原因：该库已经聚合桌游高频交付物，能最快锁定“正面图 vs 效果图 vs 规则页”的差异
  联动：`boardgame-card.md`、`boardgame-cover.md`、`boardgame-ui.md`、`boardgame-rulebook.md`

## 2. 海报与排版

- `db/海报与排版/prompt.md`
  适合：活动海报、线下印刷海报、公众号首图、电影/书籍/专辑感封面
  先看原因：本地已有 Mondo 专题与排版结构，适合先锁构图再谈风格
  联动：`Poster` 模板、`poster-artist-styles.md`

## 3. 商品与电商

- `db/商品与电商/prompt.md`
  适合：商品主图、详情页首屏、卖点图、参考图改电商图
  先看原因：能快速区分“产品摆拍”和“带信息层级的转化型海报”
  联动：`Ecommerce` 模板、`ecommerce-poster.md`

## 4. 图表与信息可视化

- `db/图表与信息可视化/prompt.md`
  适合：流程图、对比图、拆解图、规则图解、机制说明
  先看原因：这是最容易文字翻车的任务类型，先看已成型案例有助于控制模块数量
  联动：`Infographic` 模板、`infographic.md`

## 5. UI 与界面

- `db/UI与界面/prompt.md`
  适合：截图生成、平台 UI、仪表盘、直播界面、玩家面板
  先看原因：平台特征和可读文字要求高，最适合先找邻近案例再写 prompt
  联动：`UI`、`UI 截图生成`、`UI 直播界面`

## 6. 摄影与写实

- `db/摄影与写实/prompt.md`
  适合：写真、人像、商业拍摄、商品摄影、保主体写实风格改造
  先看原因：当用户想要“真实感”而不是“插画感”时，这里最能帮助锁镜头与光线
  联动：`Photo`、`街拍抓拍摄影`

## 7. 插画与艺术

- `db/插画与艺术/prompt.md`
  适合：绘本、艺术海报、风格化角色、装饰插画
  先看原因：适合从“风格表达”切入，而非从信息结构切入
  联动：`Illustration`

## 快速使用规则

- 用户要 **桌游**：先看 `桌游卡牌与版图`
- 用户要 **电商**：先看 `商品与电商`
- 用户要 **信息图**：先看 `图表与信息可视化`
- 用户要 **海报**：先看 `海报与排版`
- 用户要 **截图/UI**：先看 `UI与界面`
- 用户要 **保主体改造**：先看对应主库，再联动 `edit-workflows.md`

## Maintenance Rule

未来若某类任务连续高频出现，应优先把最成功的 3-5 个案例补进本文件，而不是继续只扩大全库正文。
