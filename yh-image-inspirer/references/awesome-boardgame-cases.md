## 为什么精选这些案例

用户当前高频工作方向：

- 桌面游戏卡牌设计
- 桌面游戏 UI 设计
- 桌面游戏封面设计
- 桌面游戏电商图设计
- 桌面游戏宣传海报设计

因此筛选标准是：

- 是否能帮助形成桌游组件、牌面、包装、宣传图的稳定结构。
- 是否有强信息层级或系列一致性。
- 是否能迁移到中文画面文字。
- 是否能减少生成时常见问题：文字乱码、风格漂移、只出效果图不出正面设计图、参考产品识别丢失。

## 可迁移专题

### A. 系列卡牌系统

来自 case 166 的核心结构：

- 多张卡保持同一边框、配色、标题区、主体区、属性区。
- 变量只换角色/图标/名称/属性。
- 适合 3x3、4x3、单张逐张生成。

桌游优化：

- 先生成变量表，再出图。
- 每张卡都重复统一视觉系统，避免“沿用上一张风格”失效。
- 中文牌面默认，不使用英文属性名，除非用户要求双语。

### B. 实体化桌游 UI

来自 case 323 的核心结构：

- UI 不只是屏幕截图，而是“可触摸的实体界面对象”。
- 材质、厚度、边缘、反光、阴影能增强真实感。

桌游优化：

- 用于玩家面板、资源盘、行动选择面板、回合记录盘。
- 明确区分“正面设计图”和“产品效果图”。
- 若是可印刷组件，禁止透视；若是电商展示，允许实体摄影效果。

### C. 机制与组件拆解

来自 case 333、334、347 的核心结构：

- 拆解视图：主体居中，组件分层，标注清晰。
- 技术信息图：标题区 + 模块区 + 箭头/编号 + 短说明。
- 动作参考表：统一网格，每格一个动作或步骤。

桌游优化：

- 可用于“怎么玩”“一回合流程”“组件说明”“卡牌效果解释”。
- 模块数量控制在 3-6 个，文字短，中文清晰。
- 避免把规则书正文塞进图里。

### D. 包装与封面 Campaign

来自 case 342、344、355、367 的核心结构：

- 单盒强主视觉：产品完整、标题明确、氛围集中。
- 四宫格 Campaign：同一产品轮廓，不同主题世界。
- 标题主导海报：游戏名成为画面最大结构。

桌游优化：

- 封面先锁定：游戏名、核心世界观、玩家人数/时长/年龄是否显示。
- 包装系列先锁定同一盒型和 LOGO 位置。
- 电商图中商品盒必须完整，不裁切关键文字。

### E. 品牌与产品线视觉板

来自 case 354、362、365 的核心结构：

- LOGO、配色、字体、包装、卡牌、token、规则书、广告物统一展示。
- 豪华版展示强调“可开箱感”和配件秩序。

桌游优化：

- 适合做 pitch deck 视觉页、众筹页、产品定位图。
- 输出不一定直接作图，也可以先输出视觉系统规范。
- 用于决定一套桌游产品的长期视觉资产，而不是单张图。
