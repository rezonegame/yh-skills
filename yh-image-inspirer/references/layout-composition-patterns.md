## 使用原则

这是“版式骨架库”，不是风格图库。使用时优先把构图词转成文字化布局约束，再结合具体视觉风格、主体、比例、文案层级。

推荐调用顺序：

1. 先判断输出形态：海报、封面、信息图、卡牌说明页、详情页首屏、社媒封面。
2. 选择 1 个主构图，最多叠加 1 个辅助构图。
3. 把构图转成空间约束：主标题位置、主视觉位置、信息区位置、留白、动线。
4. 不要同时堆 3 个以上构图词；构图过多会互相抵消。

## 快速路由

| 任务意图 | 优先构图 |
| --- | --- |
| 高级留白海报、品牌调性 | 留白式、单点、视觉中心、静态、偏重心 |
| 活动海报、远距离可读 | 垂直、居中对称、分法、主次、色块 |
| 桌游宣传海报意向风格 | X 形、环绕式、框架式、单点聚焦、动静对比 |
| 桌游宣传海报写实风格 | 前景、中景、纵深、透视、视觉动线 |
| 规则机制或卖点说明 | 分栏式、模块化、卡片式、区块式、矩阵式 |
| 电商详情页首屏 | 分割式、网格式、主次、大小对比、色彩对比 |
| 人物或角色主视觉 | 三角形、中轴、偏轴、前后、明暗 |
| 叙事型电影海报 | 层次、蒙太奇、纵深、虚实、视觉动线 |

## 高频模式卡

### 001 分法构图

参考图：`layout-001`

结构：把画面明确分成两个或多个大区域，每个区域承担不同信息任务。

适合：信息型海报、产品卖点、桌游机制宣传、活动信息海报。

Prompt 片段：

```text
使用分法构图，将画面划分为明确的信息区域：一侧为主标题与卖点，另一侧为主视觉，底部保留小字信息栏；网格清晰、留白充足、标题远距离可读。
```

### 002 九宫格构图

参考图：`layout-002`

结构：使用 3x3 网格控制主体、标题和辅助信息，重点元素落在四个交叉点或中心格附近。

适合：社媒封面、知识卡片、规则摘要、系列图统一版式。

Prompt 片段：

```text
使用九宫格构图，以 3x3 网格组织画面；主视觉位于视觉交点，标题占据高权重网格，辅助信息压缩在边缘格，整体秩序清晰。
```

### 003 黄金分割构图

参考图：`layout-003`

结构：主体沿黄金比例或螺旋路径分布，形成自然、不呆板的视觉重心。

适合：高端海报、封面、品牌主视觉、诗意插画海报。

Prompt 片段：

```text
使用黄金分割构图，主视觉沿黄金螺旋展开，标题与辅助元素按黄金比例错落排列，画面自然平衡、精致、有高级留白。
```

### 004 对称构图

参考图：`layout-004`

结构：左右或上下镜像平衡，中轴明确，形成稳定、仪式感和权威感。

适合：桌游封面、奇幻阵营海报、品牌发布、仪式感活动海报。

Prompt 片段：

```text
使用中轴对称构图，主视觉居中，左右元素形成重量平衡，标题沿中轴排列，画面稳定、庄重、仪式感强。
```

### 005 非对称构图

参考图：`layout-005`

结构：通过大小、颜色、留白和位置差异形成动态平衡。

适合：现代海报、潮流活动、视觉冲击强的社媒封面。

Prompt 片段：

```text
使用非对称构图，主视觉偏向一侧，另一侧用标题、色块或小信息组平衡画面，形成现代、灵活、有张力的布局。
```

### 010 垂直构图

参考图：`layout-010`

结构：纵向轴线突出，标题、主体和信息从上到下形成强阅读顺序。

适合：竖版海报、A3/A2 线下海报、人物海报、桌游宣传海报。

Prompt 片段：

```text
使用垂直构图，主标题竖向或纵向排列，主视觉沿画面中轴向上延展，信息从上到下分层，适合竖版海报远距离阅读。
```

### 014 留白式构图

参考图：`layout-014`

结构：大面积空白承托少量主体，强调克制、呼吸感和高级感。

适合：品牌海报、概念海报、书封、艺术展、轻奢产品。

Prompt 片段：

```text
使用留白式构图，保留大面积干净空白，只放置一个强主视觉和少量文字；画面克制、安静、高级，避免装饰过满。
```

### 017 疏密对比构图

参考图：`layout-017`

结构：密集信息区和疏朗空白区形成反差，提升节奏。

适合：信息海报、活动海报、复杂卖点整理、规则说明。

Prompt 片段：

```text
使用疏密对比构图，一侧集中标题和信息，另一侧留出空白或单一主视觉，形成清楚的节奏和阅读停顿。
```

### 025 X 形构图

参考图：`layout-025`

结构：两条对角线交叉，焦点位于交叉处，动势强。

适合：冲突、对抗、悬疑、桌游阵营对决、电影感宣传海报。

Prompt 片段：

```text
使用 X 形构图，两组对角线元素在画面中心交汇，中心形成主视觉焦点；适合表现冲突、对抗、选择和强戏剧张力。
```

### 026 放射式构图

参考图：`layout-026`

结构：元素从一个中心向外发散，形成能量释放感。

适合：新品发布、爆发感活动、技能释放、魔法/科幻主题。

Prompt 片段：

```text
使用放射式构图，光线、路径或元素从中心向四周扩散，中心标题或主体最醒目，整体有爆发、召唤、发布的能量感。
```

### 027 向心式构图

参考图：`layout-027`

结构：元素从周围指向中心，强调汇聚、目标、召集。

适合：众筹召集、团队活动、桌游聚会、核心产品展示。

Prompt 片段：

```text
使用向心式构图，周围角色、道具或信息都朝向中心主视觉，制造聚焦和召集感，中心元素成为唯一视觉锚点。
```

### 030 框架式构图

参考图：`layout-030`

结构：边框、窗口、门洞、卡框或版式边界包住主体。

适合：桌游盒面感、收藏海报、奇幻入口、展览海报、规则页。

Prompt 片段：

```text
使用框架式构图，用边框、窗口、门洞或卡牌框包裹主视觉，标题嵌入框架边缘，形成完整、精致、可收藏的海报感。
```

### 031 三角形构图

参考图：`layout-031`

结构：主体和辅助元素形成稳定三角关系，底部稳、顶部聚焦。

适合：人物群像、英雄主视觉、稳定且有层次的海报。

Prompt 片段：

```text
使用三角形构图，主角位于顶点或中心，辅助角色和场景形成稳定三角支撑，画面稳固、有史诗感。
```

### 041 单点聚焦构图

参考图：`layout-041`

结构：全画面只强调一个核心视觉焦点，其他元素退后。

适合：极简海报、单品宣传、符号化桌游海报、Mondo 风格。

Prompt 片段：

```text
使用单点聚焦构图，全画面只有一个明确核心视觉，标题和信息服务于这个焦点，避免多主体抢戏。
```

### 049 层叠式构图

参考图：`layout-049`

结构：多个图层前后叠放，制造遮挡、深度和信息层级。

适合：电影海报、桌游世界观、角色与场景复合主视觉。

Prompt 片段：

```text
使用层叠式构图，将前景角色、中景场景、背景符号分层叠放，形成遮挡关系和明确信息层级，画面丰富但不杂乱。
```

### 050 阶梯式构图

参考图：`layout-050`

结构：元素按阶梯逐级上升或下降，形成步骤感和进阶感。

适合：教程、卖点递进、等级成长、桌游回合流程说明。

Prompt 片段：

```text
使用阶梯式构图，将信息点按阶梯递进排列，数字标签清晰，视觉从低到高移动，表达成长、流程或步骤。
```

### 061 网格式构图

参考图：`layout-061`

结构：基于严格网格放置图片、文字、图标和模块。

适合：信息图、规则书、帮助卡、详情页、系列卡片。

Prompt 片段：

```text
使用网格式构图，以清晰网格组织图片、标题、说明和图标；模块间距统一，信息可快速扫描。
```

### 062 模块化构图

参考图：`layout-062`

结构：把复杂内容拆成可复用模块，每个模块承担一个信息单元。

适合：桌游组件展示、产品功能说明、课程海报、知识卡。

Prompt 片段：

```text
使用模块化构图，把内容拆成多个独立信息模块，每个模块包含小标题、图标或图片、短说明，整体保持统一网格和视觉系统。
```

### 068 卡片式构图

参考图：`layout-068`

结构：以多个卡片承载不同内容，卡片之间形成统一秩序。

适合：桌游卡牌介绍、版本对比、卖点列表、社媒组图。

Prompt 片段：

```text
使用卡片式构图，将不同卖点或组件放入统一卡片容器，卡片大小和间距一致，便于比较和阅读。
```

### 069 拼贴式构图

参考图：`layout-069`

结构：图片、便签、碎片、色块叠贴，形成手作和资料板感。

适合：旅行笔记、派对海报、桌游开箱氛围、轻松活动宣传。

Prompt 片段：

```text
使用拼贴式构图，将照片感碎片、贴纸、纸片和短文字层叠组合，形成手作资料板氛围，但保留清晰主标题。
```

### 070 蒙太奇构图

参考图：`layout-070`

结构：多个场景片段组合成一张叙事主视觉。

适合：电影海报、故事型桌游宣传、世界观介绍、角色群像。

Prompt 片段：

```text
使用蒙太奇构图，将多个关键场景片段组合为一张叙事海报，主视觉保持最大，次要片段围绕或嵌入背景。
```

### 071 引导线构图

参考图：`layout-071`

结构：用道路、箭头、光线、视线或路径引导观者到焦点。

适合：冒险桌游、路径机制、旅行海报、探索主题。

Prompt 片段：

```text
使用引导线构图，道路、光束、箭头或棋盘路径从前景引向主视觉，观者视线自然进入画面焦点。
```

### 072 透视构图

参考图：`layout-072`

结构：利用消失点、透视线和空间缩放建立深度。

适合：写实海报、空间场景、城市、室内、桌游世界入口。

Prompt 片段：

```text
使用透视构图，建立清晰消失点和空间纵深，前景、中景、背景层次明确，主体位于透视线汇聚处。
```

### 075 前景构图

参考图：`layout-075`

结构：用前景元素遮挡或框住主体，增强临场感。

适合：写实桌游宣传海报、冒险场景、沉浸式游戏世界。

Prompt 片段：

```text
使用前景构图，在画面前方放置道具、植物、角色剪影或棋子，形成遮挡和进入感，主视觉位于中景或远景。
```

### 080 深度构图

参考图：`layout-080`

结构：通过多层空间、明暗、大小和透视制造深度。

适合：电影感海报、奇幻冒险、悬疑、探索类桌游。

Prompt 片段：

```text
使用深度构图，前景暗部、中景主体、背景光源层层推进，营造可进入的空间和电影海报式纵深。
```

### 081 斜线构图

参考图：`layout-081`

结构：斜向元素制造速度、不稳定和冲击。

适合：动作、比赛、冲突、灾变、冒险。

Prompt 片段：

```text
使用斜线构图，主视觉和辅助元素沿对角线展开，形成速度感、紧张感和强烈方向性。
```

### 082 曲线构图

参考图：`layout-082`

结构：曲线引导视线流动，画面柔和、有节奏。

适合：自然、治愈、旅行、儿童向桌游、轻松活动。

Prompt 片段：

```text
使用曲线构图，路径、云雾、水流或装饰线形成柔和曲线，引导视线在标题和主视觉之间流动。
```

### 090 视觉动线构图

参考图：`layout-090`

结构：明确规划观者阅读顺序，从入口到焦点再到行动信息。

适合：任何需要清晰转化的宣传海报、众筹首图、电商海报。

Prompt 片段：

```text
使用视觉动线构图，设计明确阅读路径：先看到主标题，再进入主视觉，最后落到卖点和行动信息；箭头、视线、光线或形状方向共同服务动线。
```

### 093 主次构图

参考图：`layout-093`

结构：一个主元素绝对突出，次元素退后但补充信息。

适合：商业海报、产品首图、桌游封面、活动主视觉。

Prompt 片段：

```text
使用主次构图，主视觉占据最高权重，标题紧贴主视觉，次要卖点缩小放在边缘，避免平均分配注意力。
```

### 095 虚实构图

参考图：`layout-095`

结构：实主体与虚化/半透明/留白背景形成对照。

适合：诗意海报、悬疑、回忆、梦境、双重曝光。

Prompt 片段：

```text
使用虚实构图，核心主体清晰真实，背景或辅助元素虚化、半透明或抽象化，形成梦境、记忆或悬疑氛围。
```

### 096 明暗构图

参考图：`layout-096`

结构：用强烈明暗关系分配视觉权重。

适合：恐怖、悬疑、电影海报、写实角色主视觉。

Prompt 片段：

```text
使用明暗构图，强光集中在主体或标题区域，背景压暗，利用高对比光影建立戏剧性和聚焦。
```

### 097 色块构图

参考图：`layout-097`

结构：大色块组织版面和视觉节奏。

适合：现代海报、儿童向桌游、品牌活动、强识别社媒图。

Prompt 片段：

```text
使用色块构图，以大面积几何色块划分标题区、主视觉区和信息区，颜色少而有力，远距离识别强。
```

### 100 动静对比构图

参考图：`layout-100`

结构：动态元素与静态元素形成反差，制造节奏。

适合：桌游宣传、运动、冒险、冲突、活动海报。

Prompt 片段：

```text
使用动静对比构图，动态曲线、箭头、运动轨迹与稳定的标题/主体形成反差，画面既有冲击又保持可读。
```

## 组合建议

### 桌游宣传海报｜意向主视觉

推荐组合：

- 框架式 + 单点聚焦
- X 形 + 动静对比
- 环绕式 + 主次
- 色块 + 视觉中心

Prompt 组合句：

```text
采用框架式与单点聚焦组合构图，核心桌游符号位于画面中心，被装饰性边框、棋盘路径或奇幻门洞包围；标题清晰置于上方或下方，辅助信息极少，整体像成熟桌游宣传主视觉。
```

### 桌游宣传海报｜写实主视觉

推荐组合：

- 前景 + 纵深
- 透视 + 视觉动线
- 明暗 + 主次
- 层次 + 蒙太奇

Prompt 组合句：

```text
采用前景、纵深与视觉动线组合构图，前景道具或角色剪影制造进入感，中景呈现核心冲突，背景提供世界观；光线和路径将视线引向标题和主体，形成电影感桌游宣传海报。
```

### 信息型海报 / 规则机制图

推荐组合：

- 网格式 + 模块化
- 分栏式 + 卡片式
- 阶梯式 + 主次
- 疏密对比 + 视觉动线

Prompt 组合句：

```text
采用网格式与模块化构图，把规则、卖点、组件拆成清晰信息模块；每个模块包含小标题、图标和短说明，主标题最大，阅读顺序从左上到右下。
```

### Mondo / 概念海报

推荐组合：

- 留白式 + 单点聚焦
- X 形 + 明暗
- 色块 + 视觉中心
- 黄金分割 + 虚实

Prompt 组合句：

```text
采用留白式与单点聚焦构图，画面只保留一个象征性主视觉和极少文字，使用有限色块、丝网印刷颗粒和强负空间，形成 Mondo 概念海报感。
```

## 防坑规则

- 构图词不是风格词。必须同时指定主体、信息层级、画面文字和风格。
- 复杂海报最多选择 2 个构图模式；信息图最多选择 3 个，但要明确主次。
- “满版、密集、拼贴、蒙太奇”容易变乱，必须额外要求主标题清晰、阅读路径明确。
- “留白、单点、静态”容易变空，必须指定唯一主视觉和标题位置。
- “网格、模块、卡片”适合说明页，不适合纯氛围海报，除非用户明确要信息型海报。
- “透视、前景、纵深、深度”适合写实/电影感，不适合作为平面符号海报的主构图。
