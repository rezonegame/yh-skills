## Horror（恐怖）

**设计思路：** 氛围重于血腥、阴影与负空间、孤立元素（手/眼/武器）、哥特建筑

**配色方案：**
- Classic: Black, blood red, cream
- Gothic: Burgundy, gold, aged paper
- Psychological: Teal, rust, off-white
- Supernatural: Purple, green, black

**通用模板：**
```
[Horror element] in Mondo horror poster style, [isolated/atmospheric composition],
Gothic [architectural or natural element], [2-3 color palette], vintage [decade]
horror aesthetic, screen print with halftone shadows, [mood: dread/suspense/terror],
minimalist symbolic approach, no gore shown, suggestion over explicit imagery
```

**Slasher：**
```
Single bloody knife silhouette against suburban house window in Mondo horror poster
style, centered minimalist composition, 3-color screen print: black, blood red,
moonlight blue, vintage 1978 slasher aesthetic, halftone shadow texture, isolated
weapon as symbol of unseen threat
```

**Gothic Horror：**
```
Victorian mansion with single candlelit window in Mondo horror poster style,
Gothic arched composition, twisted bare tree silhouette in foreground, 4-color
print: black, burgundy, cream, gold, Art Deco decorative border, vintage 1931
Universal Horror aesthetic, atmospheric dread, elegant decay
```

**Psychological Horror：**
```
Fragmented mirror reflecting distorted eye in Mondo horror poster style, geometric
shattered composition, 2-color print: rust orange and teal, negative space
creating unsettling gaps, vintage 1970s psychological thriller aesthetic
```

## Science Fiction（科幻）

**设计思路：** 几何/技术精准、人类渺小对比飞船、象征性科技元素、复古未来主义

**配色方案：**
- Space Opera: Navy, silver, red accent
- Cyberpunk: Neon pink, electric blue, black
- Alien Contact: Teal, orange, cream
- Dystopian: Gray, rust, toxic yellow

**通用模板：**
```
[Sci-fi icon: helmet/ship/planet] in Mondo science fiction poster style,
[geometric/technical composition], [retro decade] futurism aesthetic, [cool
colors with accent], screen print with precise line work, vintage [60s/70s/80s]
sci-fi poster, sense of [wonder/danger]
```

**Space Exploration：**
```
Astronaut helmet reflecting alien twin suns in Mondo sci-fi poster style,
centered symmetrical composition, duotone orange and deep blue, retro 1970s
futurism, screen print with precise technical details, sense of isolation
```

**Dystopian Future：**
```
Monolithic brutalist tower piercing smog layer in Mondo dystopian poster style,
geometric vertical composition, 3-color print: industrial gray, toxic yellow,
rust, Kilian Eng technical precision, oppressive architectural scale
```

### 公众号封面（WeChat Article Cover）

**参考图：** `images/mondo_usecase-wechat-cover.png` / `images/mondo_usecase-wechat-sapiens.png`

**设计要点：**
- 比例 2.35:1（900×383px）横版
- 主标题需在手机缩略图中可读（字号大）
- 1-3 色，背景简洁，主体突出

**模板：**
```
微信公众号封面图，[主题]，横版 900x383px 比例，Mondo简化丝网印刷风格，
[单一核心视觉]，简洁背景 [主色]，标题文字 [少于10字]，clean screen print
aesthetic, readable at thumbnail size
```

### 专辑封面（Album Cover）

```

[参考风格：Joy Division极简/Blue Note爵士几何/Mondo限量版]，
[1-3色配色]，[主视觉元素]，square format 1:1，
screen print aesthetic, [mood: minimal/energetic/melancholic]
```

## Travel Poster（旅行海报）

**设计思路：** 中世纪现代旅行海报美学、复古旅游印刷品、扁平矢量或水彩拼贴

**配色方案：**
- Vintage Tourism: Cream, teal, burnt orange, gold
- Modern Minimal: 2-3 color flat palette
- Watercolor: Soft pastel, warm golden hour

**通用模板：**
```
[Middle-century / flat vector / watercolor collage] travel poster for [destination],
[landmark or scene], [color palette], [vintage tourism / Scandinavian minimalism /
mid-century modern] aesthetic, vertical layout, professional travel poster design
```

**复古矢量风（Mid-Century）：**
```
Premium editorial travel poster illustration of [destination]. Flat vector illustration,
ultra-clean minimalism, mid-century modern travel poster aesthetic, inspired by vintage
tourism prints and Scandinavian graphic design. No photorealism, no textures, no noise.
[2-3 color palette], vertical layout
```

**等距鸟瞰风（Isometric）：**
```
Vertical mid-century travel poster for [CITY] featuring [LANDMARK]. Strict 3-color
palette: cream paper, black technical linework, and [ACCENT COLOR]. Minimalist
isometric bird's-eye view with ultra-fine hatching and screen-print texture
```

**城市文字风（Typography）：**
```
Ultra-high-resolution typography travel poster themed around [CITY]. Every visible
word must be in [language], perfectly spelled, professionally typeset. City name as
dominant typographic element, integrated with landmark silhouettes
```

**水彩拼贴风（Watercolor Collage）：**
```
Watercolor and collage travel poster for [destination], vertical layout, soft pastel
and warm golden hour color palette. Scene: [waterfront/street/landmark] with [human
activities], layered paper cut-out aesthetic, hand-painted quality
```

## 国潮/新中式（Chinese Modern）

**设计思路：** 中国传统元素与现代设计融合、双重曝光、水墨质感、大面积留白、金色勾边

**配色方案：**
- 国潮经典: 朱红/墨黑/金/白
- 新中式: 荧光蓝/金/白/墨
- 节庆: 红/金/暖色
- 水墨: 黑/灰/留白

**通用模板：**
```
新中式风格海报，[主题]，[构图方式：双重曝光/水墨渲染/留白构图]，
[中国传统元素：丝绸/山水/神兽/建筑]，[色彩方案]，
大面积留白，[质感：宣纸/墨迹/金箔]，东方美学
```

**双重曝光城市风：**
```
城市宣传海报，双重曝光，S型流动构图，纯白纹理背景，
身穿中国传统服饰的微缩人物挥舞[色彩]丝绸舞带，
丝绸飘动变形为[城市]壮丽山水，叠加城市地标建筑手绘图，
云雾环绕，仙气缥缈，大面积留白，国潮风格
```

**新中式山水画风：**
```
极简主义，新中式风格立体图形设计，平整纯白亚光厚艺术纸上
绘充满东方诗意氛围的山水创意画，不规则撕纸效果，
[神兽/元素]，[线条色彩]极细金属质感勾边，泼墨大笔触，
冷暖光交织，梦幻唯美场景，框架构图，底部留白
```
