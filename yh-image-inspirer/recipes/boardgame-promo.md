# Recipe: Boardgame Promo

用于桌游宣传海报、众筹首图、电商详情页首屏、小红书种草图、发行 Campaign。

## 先判定宣传图类型

1. **单盒强主视觉海报**：一个游戏盒 + 氛围 + 标题 + 卖点。
2. **组件铺陈海报**：盒子、卡牌、token、棋盘、规则书一起展示。
3. **豪华版发布图**：配件、限定内容、包装、材质特写。
4. **玩法卖点图**：3-5 个机制卖点模块。
5. **众筹首图**：大标题 + 核心承诺 + 产品全家福 + CTA。

```json

  "game": {

  },
  "promo": {
    "type": "[单盒海报/组件铺陈/豪华版/玩法卖点/众筹首图]",

```

## 单盒强主视觉 Prompt 骨架

```text
生成一张桌面游戏中文宣传海报，游戏名为“[游戏名]”。画面比例 [比例]，适合电商首图/众筹首屏/社媒传播。

主视觉：
中央展示完整桌游盒，盒子清晰、完整，不裁切关键标题和主图。围绕盒子加入与游戏主题一致的氛围元素：[元素]。

文案：
顶部主标题：“[主标题]”
副标题：“[副标题]”
卖点标签：“[卖点1]”、“[卖点2]”、“[卖点3]”
底部行动区：“[CTA]”

视觉风格：
[风格]，商品突出，信息层级清晰，中文文字少量可读。整体像成熟桌游品牌的商业发布海报。

避免：
不要把盒子改成其他产品。不要裁切盒子。不要添加价格、二维码、水印。不要文字乱码。不要过度堆砌组件。
```

## 组件铺陈 Prompt 骨架

```text
生成一张桌游组件展示海报，展示“[游戏名]”的完整产品内容。画面包含：游戏盒、若干卡牌、token、棋盘/玩家面板、规则书。所有组件按高级电商发布图方式整齐铺陈，主盒仍是视觉中心。

加入 3 个中文卖点标签：[卖点]。背景简洁，配色与盒面统一，光线柔和，材质真实，构图干净。
```

## 豪华版发布 Prompt 骨架

```text
生成“[游戏名] 豪华版”的收藏级发布视觉。主盒、限定配件、金属 token、厚卡牌、替换组件、收纳结构和材质特写以有秩序的方式围绕主盒陈列。整体像高级收藏品发布图，具有开箱欲、稀缺感和高级感。
```
