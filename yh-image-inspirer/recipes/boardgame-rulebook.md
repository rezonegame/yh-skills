# Recipe: Boardgame Rulebook

用于桌游规则书页面、玩家帮助卡、规则摘要、回合流程页、组件说明页、教学页。

## 先判定输出类型

1. **规则书单页**：A4/Letter/方形页面，适合规则书内页。
2. **玩家帮助卡**：小尺寸信息卡，正面或双面设计。
3. **规则摘要海报**：一张图讲清核心流程，适合社媒或详情页。
4. **组件说明页**：展示组件名称、用途、数量。
5. **教学流程图**：从准备到结束的步骤说明。

默认：如果用户只说“规则书/帮助卡”，优先输出可印刷的正面页面设计图，不做桌面摆拍。

## 信息槽位

```json
{
  "document_type": "[规则书单页/玩家帮助卡/规则摘要/组件说明/教学流程图]",
  "game_title": "[游戏名]",
  "theme": "[游戏题材]",
  "page_topic": "[本页主题，例如 一回合流程]",
  "format": "[A4/Letter/1:1/4:3/9:16/卡牌尺寸]",
  "sections": [
    {"title": "[模块标题]", "content": "[短说明]", "visual": "[图标/示意图]"}
  ],
  "visual_system": {
    "palette": "[配色]",
    "typography": "[字体]",
    "icons": "[图标风格]",
    "frame": "[边框/网格]"
  },
  "text_language": "简体中文"
}
```

## 规则书页面 Prompt 骨架

```text
设计一张桌面游戏《[游戏名]》的规则书内页，主题是“[页面主题]”。画面为可印刷页面设计，纯正面平视视角，无透视，无桌面摆拍。比例 [比例]。

所有文字使用简体中文，要求清晰可读。正文不要太长，使用短句、编号和图标辅助理解。

页面结构：
顶部标题区：“[页面标题]”
副标题：“[副标题]”

主体内容分为 [3-6] 个模块：
1. [模块标题]：[一句短说明]
2. [模块标题]：[一句短说明]
3. [模块标题]：[一句短说明]

可加入：
- 小型组件图标
- 箭头流程
- 编号步骤
- 简洁示意图
- 注意事项小框

视觉风格：
与桌游《[游戏名]》的主题一致，[风格描述]。页面网格清晰，留白稳定，标题、模块、图标、说明层级分明。

质量要求：
规则书级排版、可印刷、中文可读、信息层级清晰、图标统一、模块数量克制。

避免：
不要大段正文。不要文字乱码。不要把页面做成广告海报。不要过度装饰。不要生成手机界面或网页。不要出现英文，除非用户要求双语。
```

## 玩家帮助卡 Prompt 骨架

```text
设计一张桌面游戏《[游戏名]》的玩家帮助卡正面，尺寸比例 [比例]，纯正面平视，可印刷。

内容聚焦“一回合流程”，使用 5 个编号步骤：
1. [步骤1]
2. [步骤2]
3. [步骤3]
4. [步骤4]
5. [步骤5]

每个步骤包含一个统一风格小图标、中文短标题和一句短说明。底部加入小型“常见提醒”区域，最多 2 条。

整体风格与游戏主题一致，信息密度适中，适合玩家边玩边查。
```

## 组件说明页 Prompt 骨架

```text
设计一张桌游组件说明页，展示《[游戏名]》的主要组件。纯正面可印刷页面，比例 [比例]。

组件列表：
- [组件1] x [数量]：用途 [说明]
- [组件2] x [数量]：用途 [说明]
- [组件3] x [数量]：用途 [说明]

每个组件用小型插图或图标展示，并配一行中文说明。布局采用整齐网格，避免拥挤。
```

## 结构原则

- 规则书页面服务“理解”，不要追求海报冲击力。
- 每页只解决一个主题。
- 优先编号步骤、图标、短句。
- 复杂规则拆成多页或多张帮助卡。
- 文字量越大，越需要提醒用户后续用专业排版工具二次校对。
## 网格类型参考（来源：editorial-design）

规则书和帮助卡的 `visual_system.frame` 建议按以下逻辑选择网格类型，并注入 prompt：

| 网格类型 | 适用页面类型 | prompt 关键词 |
|---------|------------|--------------|
| **Manuscript（单栏）** | 规则书正文叙述页、长段规则说明 | `single-column grid, clear margins, continuous text layout` |
| **Column（多栏）** | 组件说明页、属性对比页、帮助卡 | `two-column grid, organized sections, structured layout` |
| **Modular（模块）** | 多信息密度页（动作面板/回合流程） | `modular grid, flexible content zones, grid-based layout` |
| **Hierarchical（层级）** | 封面、规则摘要海报、教学首页 | `hierarchical layout, dominant headline element, clear visual focus` |

> 使用建议：在 `visual_system.frame` 槽位写入对应关键词，可以让 AI 生成更有结构感的规则书页面，避免随意排列。
