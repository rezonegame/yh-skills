# Recipe: Ecommerce Poster

用于商品主图、电商展示海报、卖点图、详情页首屏、参考图产品改造。

## 核心原则

参考图是严格产品参考，不是灵感图。必须保留：

- 商品名称或品牌识别。
- 包装形状和角度。
- 主色调。
- 关键图案、角色、标志、材质。
- 用户特别提到的元素。

## 信息槽位

```json
{
  "product": {
    "name": "[商品名]",
    "category": "[品类]",
    "reference_anchors": ["[必须保留1]", "[必须保留2]", "[必须保留3]"]
  },
  "poster": {
    "format": "[主图海报/详情页/卖点图]",
    "ratio": "[4:5/3:4/9:16]",
    "headline": "[中文主标题]",
    "subhead": "[中文副标题]",
    "selling_points": ["[卖点1]", "[卖点2]", "[卖点3]"],
    "cta": "[行动文案]"
  },
  "visual": {
    "background": "[背景]",
    "props": ["[辅助元素]"],
    "palette": "[配色]",
    "lighting": "[光线]"
  }
}
```

## 海报 Prompt 骨架

```text
参考用户上传的商品图片，生成一张完整的中文电商展示海报。主体商品是 [商品名/品类]，必须保留参考图中的核心识别：[识别锚点列表]。不要改变成其他产品。

画面规格：
[比例]，适合 [平台/用途]，高清完整构图。

版式：
- 顶部大标题：“[主标题]”
- 副标题：“[副标题]”
- 中央展示完整商品，商品清晰、完整，不裁切关键包装。
- 商品周围加入少量主题元素：[辅助元素]，风格与产品一致。
- 放置 [3] 个卖点标签：“[卖点1]”、“[卖点2]”、“[卖点3]”。
- 底部加入行动区：“[CTA]” 和适用场景：“[场景]”。

视觉风格：
[风格描述]。背景 [背景]，配色 [配色]，光线 [光线]。整体像专业电商主图/展示海报，商品突出，信息层级清晰，中文文字尽量清晰可读。

质量要求：
完整商品展示，商业海报排版，真实包装质感，干净背景，高清细节。

避免：
不要只生成商品效果图。不要裁掉商品。不要把产品改成其他品牌或其他包装。不要添加真实人物，除非用户要求。不要让文字乱码。不要出现价格、二维码、水印、平台 logo，除非用户要求。
```

## 默认比例

- 商品主图：1:1 或 4:5。
- 电商展示海报：4:5 或 3:4。
- 详情页长图：9:16 或更长竖版。
- 小红书种草图：3:4 或 4:5。

## 常见追问

当信息不足时最多问：

1. 这是要主图海报、详情页长图，还是单张卖点图？
2. 目标平台是淘宝/京东/小红书/公众号，还是通用电商？
3. 文字要偏销售转化，还是偏品牌展示？
