# Recipe: Infographic

用于信息图、图表、流程图、拆解图、科普图、技术讲解图。

## 先确定图表类型

常见类型：

- 流程图：步骤、机制、工作流。
- 对比图：A/B、优劣、版本差异。
- 时间线：历史、进程、计划。
- 拆解图：产品结构、系统架构、部件说明。
- 关系图：生态、网络、因果、角色关系。
- 科普海报：主题概念 + 3-6 个知识模块。

## 信息槽位

```json
{
  "topic": "[主题]",
  "audience": "[读者]",
  "chart_type": "[图表类型]",
  "title": "[中文标题]",
  "modules": [
    {"title": "[模块标题]", "text": "[一句短说明]", "visual": "[图标/小图]"}
  ],
  "style": "[白皮书/Apple keynote/手绘讲义/科技报告/儿童科普]",
  "ratio": "[9:16/16:9/4:5]",
  "constraints": ["中文可读", "模块数量克制", "层级清晰"]
}
```

## Prompt 骨架

```text
生成一张关于“[主题]”的中文信息图，目标读者是 [读者]。

图表类型：[流程图/对比图/时间线/拆解图/关系图]。
画面比例：[比例]。

结构：
顶部标题区：“[中文标题]”
主体区包含 [3-6] 个模块，每个模块包含一个简洁图标、短标题和一句短说明。

模块：
1. [标题]：[短说明]
2. [标题]：[短说明]
3. [标题]：[短说明]

视觉风格：
[风格]，配色 [配色]，背景 [背景]，信息层级清晰，留白充足。

质量要求：
中文文字清晰可读，模块数量克制，图标统一，布局平衡，适合教学/文章配图/演示。

避免：
不要大段正文。不要文字乱码。不要模块过多。不要把图表做成杂乱拼贴。不要使用无关装饰。
```
