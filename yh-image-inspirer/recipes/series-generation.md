# Recipe: Series Generation

用于同风格生成多张图片，包括系列卡牌、系列海报、系列商品图、品牌 Campaign 宫格。

## 流程

1. **品牌色锚定**（如果是品牌系列，先做此步）。
2. 锁定统一视觉系统。
3. 建立变量表。
4. 逐张生成，每张都重复统一约束。
5. 控制变化范围，避免风格漂移。

## 品牌色锚定（来源：identity-design）

生成品牌系列图前，优先确认以下信息。若用户未提供，主动询问或从已有素材中推断：

| 要素 | 说明 | prompt 写法示例 |
|-----|------|---------------|
| 主色 Hex | 品牌主色 | `brand primary color #2D6BE4` |
| 辅色 Hex | 强调色或第二色 | `accent color #FF6B35` |
| Pantone（如有） | 印刷色号，保证印刷一致性 | `Pantone 286 C` |
| Logo clear space | 最小留白区域 | `logo with clear space, do not crowd` |
| 禁止色 | 不能出现的颜色 | `avoid red and purple tones` |

> 约束写法：用具体 hex 值锁定品牌色，比模糊的颜色词（如"蓝色"）准确得多。
> 例：`brand colors: primary #1A73E8, accent #FBBC04, neutral #F8F9FA`

## 统一视觉系统

至少锁定：

- 画幅比例。
- 背景或版式结构。
- 主色和强调色。
- 字体语言和文字数量。
- 主视觉占比。
- 边框、材质、光影。
- 禁止项。

## 变量表

```markdown
| 序号 | 名称 | 主视觉 | 关键数值/卖点 | 规则/文案 | 小变化 |
| --- | --- | --- | --- | --- | --- |
| 1 |  |  |  |  |  |
```

如果用户只给“不同名字生成 N 张”，可以主动补齐合理变量，但要保持主题一致。

## Prompt 写法

每张都应包含：

- “这是同系列第 X 张”
- “必须保持统一视觉系统”
- 当前图的变量
- 统一禁止项

不要只说“沿用上一张风格”，图像生成模型不一定能继承上下文。

## 批量数量

- 1-5 张：可以直接逐张生成。
- 6-12 张：建议先输出变量表确认，再生成。
- 12 张以上：建议分批。
