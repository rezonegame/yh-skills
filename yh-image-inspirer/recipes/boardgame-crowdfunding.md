# Recipe: Boardgame Crowdfunding

用于桌游众筹详情页长图、Kickstarter/摩点/小程序众筹首屏、产品卖点长图、发行页视觉结构。

## 先判定输出类型

1. **众筹首屏**：强主视觉 + 核心卖点 + CTA。
2. **详情页长图**：多段式长图，展示世界观、玩法、组件、卖点、版本。
3. **豪华版发布页**：突出升级组件、限定内容、材质和收藏价值。
4. **玩法解释长图**：用图文模块讲清怎么玩。
5. **版本对比图**：基础版、豪华版、扩展包、全收纳版。

默认：如果用户说“众筹图/详情页”，优先做竖版长图结构；如果用户说“首图/首屏”，优先做 4:5 或 3:4 强主视觉。

## 众筹首屏 Prompt 骨架

```text
生成一张桌面游戏《[游戏名]》的中文众筹首屏视觉，比例 [比例]，适合 Kickstarter/摩点/电商预售页。

主视觉：
完整展示游戏盒和核心组件，包括 [组件列表]。游戏盒是视觉中心，组件围绕盒子有秩序陈列。背景体现 [世界观/题材]，但不能抢走产品主体。

文案：
主标题：“[游戏名]”
核心口号：“[一句话卖点]”
信息标签：“[玩家人数]”、“[游戏时长]”、“[年龄]”
三大卖点：“[卖点1]”、“[卖点2]”、“[卖点3]”
行动文案：“立即支持”或“加入首发”

视觉风格：
[风格描述]。整体像成熟桌游众筹项目首屏，产品可信、世界观吸引人、卖点清晰。

避免：
不要价格和二维码。不要平台 logo。不要文字乱码。不要组件堆成杂乱拼贴。不要裁切游戏盒标题。
```

## 详情页长图 Prompt 骨架

```text
生成一张桌面游戏《[游戏名]》的中文众筹详情页长图，竖版长图结构，适合电商/众筹页面。

整体结构分为 6 个段落：

1. 首屏主视觉
标题“[游戏名]”，口号“[一句话卖点]”，完整游戏盒与核心组件。

2. 世界观介绍
用一张氛围插图和 2-3 个关键词展示 [世界观]。

3. 核心玩法
用 3-5 个步骤说明怎么玩：
[步骤1]、[步骤2]、[步骤3]、[步骤4]、[步骤5]

4. 组件展示
整齐展示盒子、卡牌、token、棋盘、玩家面板、规则书，每个组件一行短说明。

5. 三大卖点
用图标卡片展示：“[卖点1]”、“[卖点2]”、“[卖点3]”。

6. 支持行动区
写“立即支持 / 加入首发 / 解锁更多内容”，保持简洁。

视觉要求：
分段清晰，标题大，正文短，中文可读。配色、图标、边框和插画风格统一。像专业桌游众筹详情页，而不是普通海报。

避免：
不要大段规则文字。不要乱码。不要平台 logo、二维码、价格，除非用户要求。不要把组件和世界观元素混成杂乱拼贴。
```

## 版本对比 Prompt 骨架

```text
生成桌游《[游戏名]》的版本对比图，展示基础版、豪华版、扩展包三个版本。使用清晰三栏表格或卡片布局，每栏包含盒子/组件图、版本名称、包含内容、适合人群和推荐标签。中文文字清晰可读，信息简洁。
```

## 结构原则

- 众筹页不是单张美图，而是“购买决策结构”。
- 顺序通常是：吸引 -> 可信 -> 会玩 -> 有料 -> 想买。
- 组件图和玩法图比抽象氛围图更能转化。
- 每段只放一个核心目标，避免一个画面承担太多。
