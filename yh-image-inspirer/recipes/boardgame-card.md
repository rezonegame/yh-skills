# Recipe: Boardgame Card

用于实体桌游卡牌、游戏卡牌、牌面 UI、卡牌系列、卡牌商品效果图。

## 先判定输出形态

用户说“卡牌”时，不要默认做产品摆拍。先判断或补齐以下模式：

1. **牌面正面图**：可印刷、纯正面、平面正交、无透视、无桌面。
2. **产品效果图**：卡牌在桌面/手中/包装旁，展示材质和真实感。
3. **系列卡牌**：多张同风格，不同名字、主体、属性或规则。
4. **卡牌合集图**：多张牌在同一画面，以宫格或扇形展示。

如果用户没有说明，默认使用 **牌面正面图**。

## 信息槽位

```json
{
  "card_name": "[卡名]",
  "card_type": "[类型/阵营/资源/角色/事件]",
  "subtitle": "[副标题]",
  "hero_visual": "[中心图标/角色/物品]",
  "stats": [
    {"label": "[中文属性]", "value": "[数值]"}
  ],
  "rule_text": "[一条短规则]",
  "rarity": "[普通/稀有/史诗/传说，可选]",
  "visual_system": {
    "frame": "[边框]",
    "palette": "[配色]",
    "typography": "[字体气质]",
    "material": "[纸张/金属油墨/镭射/压纹]"
  }
}
```

## 牌面正面图 Prompt 骨架

```text
生成一张 [比例] 的实体桌游卡牌正面设计图，纯正面平视视角，完整卡牌居中展示。不要桌面、不要透视、不要产品摄影场景、不要手持、不要背景道具。画面只呈现卡牌正面版式本身，像可直接用于印刷或导入桌游卡牌系统的卡面设计。

所有牌面信息必须是简体中文，不要出现英文。文字必须少量、清晰、可读，避免乱码。

卡牌名称：[卡名]
副标题：[副标题]
卡牌类型：[类型]

主体视觉：
中央放置 [中心图标/角色/物品]，作为最强视觉锚点。主体占卡面约 [30%-45%]，风格为 [风格]，保持清晰、平面化、可读。

版式结构：
顶部标题区 + 中央主视觉 + 周边属性模块 + 底部规则栏。四周保留稳定边框，边框风格为 [边框]。属性模块数量为 [4-6] 个，均匀分布，不要拥挤。

属性模块：
[属性1] [数值]、[属性2] [数值]、[属性3] [数值]、[属性4] [数值]

底部规则栏：
写：“[规则短句]”

视觉风格：
[统一视觉系统]。整体干净、对称、信息层级清晰，适合实体印刷。

避免：
不要生成桌面摆拍。不要生成倾斜卡牌。不要生成卡牌包装盒。不要生成手机界面。不要出现英文。不要让文字乱码。不要让数值太多或太小。
```

## 系列卡牌规则

- 先锁定统一视觉系统，再生成每张卡。
- 每张卡只改变：卡名、中心图标、属性值、规则文本、少量强调色。
- 每张 prompt 都重复核心一致性约束，不要只在第一张里写。
- 如果用户要求 5 张以内，可以直接逐张生成。更多数量时，先输出批量表格让用户确认。

## 常见追问

当信息不足时最多问：

1. 你要牌面正面图，还是带桌面/包装的效果图？
2. 画面文字要中文、英文还是双语？
3. 是否要同一套系列风格？
