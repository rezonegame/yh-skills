# Recipe: Boardgame Cover

用于桌游盒面、封面主视觉、扩展包封面、系列包装。

## 先判定封面类型

1. **盒面正面设计图**：纯正面、可印刷、无透视。
2. **完整盒子效果图**：带侧面厚度，适合电商。
3. **宣传封面海报**：封面视觉扩展成广告海报。
4. **系列包装宫格**：多个扩展包或阵营盒。

默认：如果用户说“封面设计”，优先做 **盒面正面设计图**。如果用户说“电商展示”，做完整盒子效果图或海报。

## 盒面正面 Prompt 骨架

```text
设计一张桌面游戏盒面正面图，游戏名为“[游戏名]”。纯正面平视视角，完整盒面居中展示，像可直接用于印刷的封面设计，不要透视，不要桌面摆拍，不要包装样机。

所有文字使用简体中文，文字少量、清晰、可读。

标题区：
主标题：“[游戏名]”
副标题：“[副标题]”
可选信息：“[玩家人数] / [游戏时长] / [年龄]”

主视觉：
[主视觉描述]，必须成为画面焦点。辅助元素包括：[辅助元素]。整体传达 [世界观/体验]。

版式：
[构图]。标题与主视觉关系明确，LOGO/标题不要被遮挡，底部可保留小型出版信息区。

视觉风格：
[风格、配色、材质、光影]。封面要像成熟桌游产品，不要像普通插画练习。

避免：
不要生成电商海报。不要生成盒子侧面。不要生成价格、二维码、水印。不要英文，除非用户要求双语。不要让标题乱码。
```

## 系列包装 Prompt 骨架

```text
生成一组 2x2 桌面游戏扩展包封面宫格。四个封面保持同一游戏 LOGO、同一盒型、同一标题位置和统一视觉系统，但每个扩展包有不同主题世界、主色和主视觉。

四个扩展包：
1. [名称/主题/主色/主视觉]
2. [名称/主题/主色/主视觉]
3. [名称/主题/主色/主视觉]
4. [名称/主题/主色/主视觉]

要求：每个封面都像可独立销售的桌游盒面，中文标题清晰，系列感强，差异明确。
```
