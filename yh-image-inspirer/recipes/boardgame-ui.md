# Recipe: Boardgame UI

用于桌面游戏 UI、玩家面板、资源盘、行动面板、回合轨、计分板、帮助卡、规则辅助界面。

## 先判定 UI 类型

1. **印刷正面设计图**：纯正面、可印刷、无透视，用于 player board / dashboard / aid card。
2. **实体组件效果图**：桌面摆拍或棚拍，用于电商展示。
3. **数字 App UI**：配套 App、计分器、教学界面。
4. **规则信息 UI**：回合流程、行动说明、资源转化表。

默认：如果用户没有说明，优先做 **印刷正面设计图**。


## Prompt 骨架

```text
生成一张桌面游戏 [UI 类型] 的正面设计图，主题为“[主题]”。画面是可印刷的平面 UI，不是手机 App，不是网页，不是桌面摆拍。纯正面平视视角，完整组件居中展示，比例 [比例]。

所有界面文字必须是简体中文，少量、清晰、可读。

版式区域：
1. [区域1]：用于 [用途]，包含 [组件]
2. [区域2]：用于 [用途]，包含 [组件]
3. [区域3]：用于 [用途]，包含 [组件]

视觉系统：
[配色、边框、图标、材质]。整体像真实桌游组件的专业印刷稿，信息层级清晰，图标统一，槽位对齐，留白稳定。

质量要求：
桌游 UI 设计、玩家面板、可印刷、平面正交、中文可读、图标清晰、模块边界明确。

避免：
不要生成手机界面。不要生成网页。不要桌面摆拍。不要倾斜透视。不要英文。不要乱码。不要让模块过多导致拥挤。
```

## 结构建议

- 玩家面板：顶部标题 + 左侧资源区 + 中央行动区 + 右侧状态区 + 底部回合提示。
- 资源盘：中心主题图标 + 环形资源轨 + 数值槽位 + 标记物放置区。
- 帮助卡：一回合流程 3-6 步 + 图标 + 短说明。
- 计分板：分数轨 + 阶段奖励 + 图标图例。
