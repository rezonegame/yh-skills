# Open Design Prompt Gallery

来源：`nexu-io/open-design/assets/prompt-templates`。本目录只保留 JPG 参考图，未复制 MP4。

## 适合场景

- 游戏、故事板、动作分镜、古风叙事：参考 `game-screenshot-*`、`video-seedance-*poster.jpg`。
- UI/HUD/界面感底图：参考 `game-ui-*`。
- 教育/儿童手绘/低龄表达：参考 `illustration-crayon-*`。
- 多格信息图或舞蹈/动作拆解：参考 `infographic-*`、`social-media-post-*`。

## 2C 强约束

使用这些图做 2C 灵感时，只能借镜头、空间和角色关系；底图生成提示词必须禁止可读文字，并预留 PPT 文本框区域。
