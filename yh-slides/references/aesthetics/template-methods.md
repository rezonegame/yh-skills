# Template Methods

> 用途：给 `yh-slides` 提供本地化的质量基线、页型 archetype 和模板矿化规则。这里记录的是方法层，不是外部模板索引；使用时不需要访问任何外部仓库。

## 独立技能原则

- 只使用本技能目录内的说明、种子文件、样式规则和资产。
- 外部项目只作为已吸收的方法来源，不作为运行时依赖。
- 不引入远程模板、远程图片、远程脚本、外部 slide runtime 或外部索引资产。
- 模板资产后续若要内置，必须先有精选标准、许可证记录、中文适配说明和 QA 结果。

## 质量基线类型

在 Step 4 展示风格选择前，先内部判断本次成品应对齐哪类高质量演示。通常不需要问用户，只需在推荐理由中说明。

| 基线 | 适合 | 推荐视觉姿态 | 常见风险 |
|---|---|---|---|
| 产品发布型 | 新产品、功能发布、路演、发布会 | 强封面、清晰价值主张、能力分层、CTA 明确 | 容易营销腔过重 |
| 技术解释型 | API、工程方案、架构、概念科普 | 结构图、流程图、对比页、代码/术语克制使用 | 容易堆细节、文字太密 |
| 知识课程型 | 教学、培训、工作坊、课堂讲授 | 渐进拆解、例题、检查点、复习页 | 容易像讲义，视觉张力不足 |
| 工作流演示型 | 工具流程、操作指南、方法论、业务流程 | 步骤分解、前后对比、任务卡、状态变化 | 容易变成普通说明书 |
| 强视觉叙事型 | keynote、读书分享、观点表达、展览式演示 | 少字、强节奏、转场页、图像和金句 | 信息密度可能不足 |
| 商业汇报型 | 企业汇报、项目复盘、咨询报告、投资材料 | 结论先行、数据页、风险页、路线图 | 容易模板化或过度正式 |

## 页型 Archetype

Step 3-B 生成逐页大纲后，必须做页型覆盖检查。目标不是凑满 20 页，而是避免所有页面都退化成 bullet dump。

| 页型 | 用途 | 何时使用 |
|---|---|---|
| Cover | 建立主题、气质和第一印象 | 每个 deck 必备 |
| Agenda | 告知结构和预期 | 8 页以上、正式汇报、课程 |
| Problem / Context | 说明问题背景或冲突 | 需要先建立必要性时 |
| Framework | 给出方法、模型或分类 | 方法论、课程、咨询内容 |
| Content | 承载核心知识或论点 | 普通讲解页，但避免连续过多 |
| Metrics / Data | 呈现关键数字和结论 | 有数据、指标、趋势时 |
| Timeline / Roadmap | 表达时间、阶段和计划 | 项目、历史、路线图 |
| Diagram / Architecture | 表达系统、关系、流程 | 架构、机制、因果、组织结构 |
| Quote / Key Insight | 强调一句关键洞察 | 需要节奏停顿或观点锚点 |
| Comparison | 对比方案、前后、优劣 | 多方案、竞品、变更说明 |
| Process / Workflow | 展示步骤、操作和流转 | 工具、SOP、教学任务 |
| Matrix / 2x2 | 同时比较两个维度 | 策略分类、优先级、定位 |
| Table / Spec | 承载细节规格 | 必须精确列项时，避免太大表 |
| Case Study | 用案例证明观点 | 培训、销售、复盘 |
| Checklist | 总结可执行项 | 课程、方法论、行动指南 |
| Risks / Tradeoffs | 主动暴露代价和边界 | 决策、方案、路线图 |
| FAQ / Appendix | 承接补充问题 | 正式答辩、技术说明 |
| Closing / CTA | 收束、行动、联系方式 | 每个 deck 建议具备 |

## 页型覆盖检查

1. 读完整体标题线，确认只读标题能否讲出完整故事。
2. 标出每页 archetype；连续 3 页以上都是 Content/Bullet 时必须改造。
3. 遇到数据、流程、架构、时间线、多方案比较，优先考虑图表或示意图。
4. 每 3-4 页插入一次转场、洞察、so what 或行动页。
5. 页数少时保持克制：5-8 页不需要 Agenda 或 Appendix，除非是正式汇报。

## 模板矿化流程

模板只提供设计语言，不提供运行时。使用本地模板或本地风格参考时，按下面顺序抽取：

1. **Palette**：主背景、正文、弱文本、强调色、危险/成功色。
2. **Typography**：中文/英文/数字字体倾向，display/H1/H2/body/caption 的层级。
3. **Spacing**：页边距、栏宽、卡片间距、留白密度。
4. **Cards / Panels**：卡片圆角、边框、阴影、底色、信息密度。
5. **Diagrams**：箭头、节点、流程、矩阵、数据可视化的形态。
6. **Layout rhythm**：封面、正文、反差页、转场页、收束页如何交替。
7. **Page archetype**：这套语言最适合哪些页型。

## 禁止迁移内容

- 第三方品牌 logo、lockup、专有产品图。
- 远程图片、远程字体、远程脚本、外部导航脚本。
- 外部 runtime 或 daemon。
- 与当前受众、语言、交付格式不匹配的特效。
- 没有来源说明或许可证记录的可识别素材。
