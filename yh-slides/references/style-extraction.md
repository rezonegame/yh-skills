# 风格提取 (Style Extraction)

## 概述

用户上传参考图片时，可使用 AI 提取其视觉风格，自动生成风格描述，用于 Step 2 设计系统选择或直接作为生图 prompt 的一部分。

## 使用场景

1. **风格参考**: 用户说"我喜欢这个PPT的风格"并上传图片 -> 提取风格描述
2. **模仿设计**: 用户要求模仿某个设计 -> 提取后匹配 `proven-styles-gallery.md` 中最接近的风格
3. **品牌定制**: 用户需要品牌定制 -> 提取品牌视觉 DNA

## 提取 Prompt

```
你是一位专业的 PPT 设计分析师。分析这张图片并提取详细的风格描述，用于生成具有相似视觉风格的 PPT 幻灯片。

重点关注：
1. 色板：主色、辅色、强调色、背景色
2. 字体风格：印象（衬线/无衬线、粗细、字号层级）
3. 设计元素：装饰图案、形状、图标风格、边框、阴影
4. 整体情绪：专业、活泼、极简、商务、创意等
5. 布局倾向：内容排列方式、间距偏好

输出一段简洁的中文风格描述，可直接用作 PPT 生成的风格提示词。
```

## CLI 命令

```bash
# 提取风格描述并输出到终端
python ~/.claude/skills/yh-slides/scripts/generate_image.py extract-style --image reference.png

# 提取风格描述并保存到文件
python ~/.claude/skills/yh-slides/scripts/generate_image.py extract-style --image ref.png --output style.txt
```

## 输出示例

```
采用深蓝色渐变背景，搭配白色和金色文字。整体风格简约商务，使用无衬线字体，标题加粗突出。
页面装饰以几何线条和半透明色块为主，配色统一协调。内容区域留白充足，视觉层次分明。
```

## 与 Step 2 设计系统的整合

### 方式 1: 匹配已有风格

提取风格描述后，与 `proven-styles-gallery.md` 中 18 种风格进行比对：

1. **色板相似度** -> 缩小到 2-3 种候选
2. **情绪匹配** -> 选出最终风格
3. 向用户展示匹配结果，确认或微调

### 方式 2: 自定义风格

无法匹配已有风格时，基于提取结果创建自定义 Base Style Prompt：

```
[提取的色板描述], [提取的字体风格], [提取的设计元素], [提取的布局倾向]
```

### 方式 3: 品牌视觉 DNA

参考 `design-principles.md` 中的品牌定制指南，提取特定角色/品牌的视觉特征。

## 提取维度详细说明

| 维度 | 提取内容 | 用途 |
|------|---------|------|
| 色板 | 主色 + 辅色 + 强调色 + 背景色 | Base Style Prompt 配色 |
| 字体 | 衬线/无衬线、粗细、层级 | 排版规则 |
| 设计元素 | 图案、形状、图标、边框 | Visual language |
| 情绪 | 专业/活泼/极简/商务/创意 | 风格家族匹配 |
| 布局 | 排列方式、间距 | 页面模板选择 |

## 提取流程

```
用户上传参考图片
        |
        v
  AI 视觉分析（使用上述提取 Prompt）
        |
        v
  生成风格描述文本
        |
        v
  ┌─────────────────────────────────┐
  │     匹配 proven-styles-gallery   │
  │                                 │
  │  匹配成功?                      │
  │  YES -> 使用已有风格参数         │
  │  NO  -> 创建自定义风格 Prompt    │
  └─────────────────────────────────┘
        |
        v
  用户确认 / 微调
        |
        v
  应用于幻灯片生成
```

## 注意事项

- 提取结果应以**中文**输出，确保与 yh-slides 工作流一致
- 风格描述应**简洁具体**，避免模糊词汇（如"好看"、"高级感"）
- 当参考图片为截图时，需提醒用户截图质量可能影响提取精度
- 品牌定制场景下，建议用户提供多张参考图以提取更稳定的视觉 DNA
