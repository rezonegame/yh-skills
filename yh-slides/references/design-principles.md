# 设计原则框架

## 核心设计原则

### 5/5/5 规则

- 每行 ≤5 个词
- 每张幻灯片 ≤5 个要点
- 连续文字幻灯片 ≤5 张

### 认知负荷管理

- **一页一观点** — 每张幻灯片只传达一个核心信息
- **约 1 分钟/页** — 每张幻灯片的讲解时间约 1 分钟
- **演讲补充，而非重复** — 幻灯片补充演讲内容，永远不要照读

### 视觉层次

- **F/Z 阅读模式** — 视线自然流动路径
- **标题:正文字号比 ≈ 3:1** — 建立清晰的层次关系
- **每页必有视觉元素** — 图像、图表、图标、装饰形状

---

## 反 AI 审美铁律（严格禁止）

以下模式会让设计看起来像"AI 生成的千篇一律模板"：

- ❌ 圆角卡片堆叠（rounded card stacks）
- ❌ Glow/blur 装饰效果（发光/模糊装饰）
- ❌ 图标当视觉主角（icons as hero elements）
- ❌ 渐变色滥用（gradients everywhere）
- ❌ 蓝+紫组合（blue+purple combo）
- ❌ 一切居中对称（everything centered）
- ❌ 千篇一律的 hero section（identical hero layouts）

---

## 设计自觉

优秀设计应该具备：

- ✅ **配色有出处** — 每个颜色选择都应该有灵感来源（杂志、展览、品牌）
- ✅ **留白是静默表达** — 留白不是"空白"，而是设计的呼吸
- ✅ **动效服务叙事** — 动画应该强化故事，而非炫技
- ✅ **版式追求不对称平衡** — 完全对称=死板，微妙不对称=生动

## 排版规则

### 字体选择

- 最多 2 个字体家族（1 标题 + 1 正文）
- 标题：bold，有个性 — ≥36pt（趋势：更大，作为图形表面）
- 正文：clean，可读 — ≥18pt
- 中文：系统默认（PingFang SC / Microsoft YaHei）

### 关键原则

排版是**设计元素**，不仅仅是信息容器。

### Section Label 用法

英文 section label（如 INSIGHT、TAKEAWAY、PART 03）可作为设计元素使用，提升视觉层次。

---

## 内容规则

### 语言规则

- 幻灯片内容一律用**中文**
- 仅保留必要的英文术语（人名、品牌名、技术专有名词）
- Section label 可用英文作为设计元素

### Assertion-Evidence 规则

标题应该是完整的论断句，而非主题词：

| 差的标题 | 好的标题 |
|---------|---------|
| Q3 Sales | Q3销售增长23%，新用户是主要驱动力 |
| Methodology | 我们通过双盲实验验证了这个结论 |
| 市场分析 | 90后已成为最大的消费群体 |
| 技术架构 | 微服务架构降低了60%的部署时间 |

## 视觉叙事策略

### 效果→感受映射

| 目标感受 | 设计手法 |
|---------|---------|
| 戏剧感/电影感 | 慢速淡入(1-1.5s)、大缩放过渡、深色背景+聚光灯、视差滚动、全出血图片 |
| 科技感/未来感 | 霓虹发光效果、粒子系统背景、网格图案、等宽字体、青色+品红+电蓝配色 |
| 活泼/友好 | 弹性缓动、大圆角、明亮/柔和色彩、浮动动画、手绘元素 |
| 专业/商务 | 微妙快速动画(200-300ms)、无衬线字体、深蓝/石板色背景、精确间距、数据可视化 |
| 沉静/极简 | 非常缓慢微妙的运动、大量留白、柔和色调、衬线字体、内容为王 |
| 编辑/杂志 | 强排版层次、引用标注、图文交织、打破网格、衬线标题+无衬线正文 |

## 幻灯片内容结构

### 标准结构

1. 封面（1 张）
2. 目录/概览（1 张，可选）
3. 主要内容（4-8 张）
4. 总结/结论（1 张）
5. 结束页（1 张）

### 内容密度限制

| 幻灯片类型 | 最大内容 |
|-----------|---------|
| 标题页 | 1 标题 + 1 副标题 |
| 内容页 | 1 标题 + 4-6 要点（每项最多 2 行） |
| 特性网格 | 1 标题 + 6 卡片（2x3 或 3x2） |
| 代码页 | 1 标题 + 8-10 行代码 |
| 引用页 | 1 引用（最多 3 行）+ 来源 |
| 图片页 | 1 标题 + 1 图片（最大 60vh） |

**内容超限？→ 拆分为多页，永远不要滚动。**

## 品牌定制指南

当用户提到特定角色/动漫风格时，提取其视觉 DNA 构建设计系统：

| 用户说 | 提取视觉特征 |
|-------|-----------|
| "哆啦A梦风格" | 圆形、明亮蓝+白+红、简单背景、可爱比例、神奇道具 |
| "吉卜力风格" | 水彩质感、自然绿+天空蓝、精细背景+简单角色、温暖奇幻 |
| " Calvin and Hobbes" | 动态水墨笔触、表现性运动线、奇幻与现实对比 |
| "One Piece" | 粗犷动感线条、夸张比例、戏剧动作姿态、高能量 |
| "蜡笔小新" | 粗犷蜡笔线条、平面亮色、搞笑比例、日常场景 |

**自定义风格模板**:
```
[用户风格]: "[参考名称]"
→ 形状语言: [圆润/锐利/几何/有机]
→ 线条质量: [细均匀/粗变化/手绘/笔触]
→ 色彩方案: [从该美学提取的具体颜色]
→ 角色风格: [比例、表情程度]
→ 背景处理: [精细/极简/抽象]
→ 情绪基调: [温暖/活力/哲理/超现实]
```
