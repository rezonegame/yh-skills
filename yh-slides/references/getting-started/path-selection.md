# 意图驱动路径选择（Path Selection）

> 先判断用户要交付什么，再映射到用户侧产物选项；随后再选择内部执行路径。路线码仍可用，但普通用户不需要先理解 `1B + 2A + 3B`。

命名原则见 [product-path-taxonomy.md](./product-path-taxonomy.md)：`2A/2B/2C/2D` 是产物选项，`Path A/B/H/C/D/E` 是内部执行路径。

离线资产升级后新增三个专项分支，但默认不替代原有推荐：

- `2A-S / Path S`：复杂图表、原生形状、矢量可编辑、避免 HTML 转换偏移时推荐。
- `2A-T / Template Fill`：用户已有 PPTX 模板且要求保留原设计时推荐。
- `2D-P / Presenter Mode`：演讲、分享、逐字稿、speaker notes、提词器、怕忘词时推荐。

## 快速决策树

```
Q1: 最终交付是 PPTX 还是 HTML？
  │
  ├─ PPTX
  │    │
  │    ├─ Q2: 是否需要稳定后期编辑文字、形状、图表或版式？
  │    │    ├─ 是 → 2A 通用可编辑 PPTX（简易 HTML 转换） → Path A
  │    │    └─ 否 → Q3
  │    │
  │    ├─ Q3: 是否追求最强视觉、最接近样张，并接受文字基本不可编辑？
  │    │    ├─ 是 → 2B 整图视觉 PPTX → Path B
  │    │    └─ 否 → Q4
  │    │
  │    ├─ Q4: 是否想要好看，同时课堂/汇报文字能改？
  │    │    ├─ 是 → 2C 视觉底图 + 可编辑文字 PPTX → Path H
  │    │    └─ 否 → 2A 通用可编辑 PPTX（简易 HTML 转换） → Path A
  │    │
  │    └─ 特殊：输入已经是位图，且要恢复可编辑结构
  │         └─ 2B-R / FigEdit Reconstruction
  │
  └─ HTML / 浏览器 / 网页 / 交互展示
       │
       └─ 2D 多功能 HTML 演示
            │
            ├─ 需要长期维护、复杂交互或组件复用？
            │    ├─ 是 → Path E（Local React Deck）
            │    └─ 否 → Q5
            │
            ├─ Q5: 是否需要动画或配音？
            │    ├─ 是 → Path D（GSAP + TTS 富交互演示）
            │    └─ 否 → Path C（单文件网页演示）
            │              │
            │              └─ 要精品杂志感还是轻量网页？
            │                   ├─ 精品 → Path C + magazine 种子
            │                   └─ 轻量 → Path C + minimal 种子
```

## 产物选项对比

| 维度 | 2A 通用可编辑 PPTX | 2B 整图视觉 PPTX | 2C 视觉底图 + 可编辑文字 PPTX | 2D 多功能 HTML 演示 |
|------|-------------------|------------------|------------------------------|--------------------|
| 内部路径 | Path A | Path B | Path H | Path C / D / E |
| 输出格式 | PPTX | PPTX | PPTX | HTML / 静态网页 |
| HTML 角色 | 中间稿，用于转 PPTX | 不需要 | 可选组装辅助，不是核心 | 最终作品 |
| 文字可编辑 | PowerPoint 中可编辑 | 基本不可编辑 | PowerPoint 中可编辑 | 改 HTML/CSS/React |
| 图片角色 | 局部配图/照片/插画 | 整页完整图 | 整页无正文文字视觉底图 | 网页配图、动画素材、交互素材 |
| 稳定性 | 高 | 高 | 中-高 | Path C 高；Path D/E 取决于动效和工程复杂度 |
| 适合 | 正式汇报、可维护材料、课程讲义 | 海报级视觉、样张复刻 | 教学/汇报好看且要改字 | 网页分享、动画配音、复杂交互 |

## 内部路径说明

| 内部路径 | 所属产物 | 说明 |
|---|---|---|
| `Path A` | `2A` | 简易 HTML 中间稿 -> `html2pptx` -> 可编辑 PPTX。必须遵守 720×405pt、absolute、安全区和文本框规则。 |
| `Path B` | `2B` | 整页 AI 图片 -> 图片型 PPTX。允许文字在图里，但必须检查文字准确性。 |
| `Path H` | `2C` | 混合型 PPTX。无正文文字视觉底图 + PPT 原生文本框；不需要位图逆向重建。 |
| `Path C` | `2D` | 单文件网页演示。HTML 是最终交付物，不转 PPTX。 |
| `Path D` | `2D` | 动画 + 配音 HTML。适合自动播放和课堂导览。 |
| `Path E` | `2D` | 本地 React/TSX 演示工程。适合长期维护、复杂交互和静态部署。 |
| `FigEdit Reconstruction / 2B-R` | `2B-R` | 已有位图经语义拆解重建为可编辑 SVG、原生 PPTX、Manifest 和质量报告。 |

## 典型场景推荐

- 企业季度汇报 → **2A 通用可编辑 PPTX（简易 HTML 转换）**
- 咨询级复杂图表 / 原生矢量可编辑 / 不要 HTML 偏移 → **2A-S 高保真原生可编辑 PPTX**
- 已有公司 PPTX 模板，要保留原设计并填充新内容 → **2A-T 原生 PPTX 模板填充**
- PPT 原生可编辑，还要加一点插画/照片 → **2A**
- 产品发布会视觉，文字不需要改 → **2B 整图视觉 PPTX**
- 教学课件要好看，中文标题/要点/互动题要能改 → **2C 视觉底图 + 可编辑文字 PPTX**
- 已有位图幻灯片、截图或论文图，希望恢复文字、结构、连接线、公式和可替换资产 → **2B-R / FigEdit Reconstruction**
- 个人创作分享 / 电子杂志感 → **2D 多功能 HTML 演示 / Path C magazine**
- 单文件网页分享 → **2D / Path C**
- 技术分享 / 演讲 / 需要逐字稿或提词器 → **2D-P Presenter Mode**
- 教学课件含自动配音 → **2D / Path D**
- 长期维护的网页演示 / 复杂交互 → **2D / Path E**

---

## 样稿默认规则

- 快速草稿：默认不强制样稿；2B/2C 建议至少 1 页。
- 标准制作：2A、2A-S、2A-T 建议样稿或 2-3 页验证；2B、2C、2D、2D-P 强制样稿或首屏/动效/presenter 原型。
- 精品交付：所有产物选项强制样稿。
- 有品牌规范、参考图或旧 PPT：强制样稿校准方向。

## 不确定时的最稳选择

- 想要 PPTX 且正式可维护 → **2A**
- 想要 PPTX 且复杂图表/原生形状更重要 → **2A-S**
- 想复用现成 PPTX 模板 → **2A-T**
- 想要 PPTX、好看、文字能改 → **2C**
- 想要最强视觉且不用改字 → **2B**
- 已有位图后需要恢复可编辑结构 → **2B-R**
- 想要网页分享或浏览器播放 → **2D**
- 想要演讲者视图/逐字稿 → **2D-P**
- 想要单文件网页 → **2D / Path C**
- 想要可维护网页工程 → **2D / Path E**
