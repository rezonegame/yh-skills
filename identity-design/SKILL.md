# Brand Identity Design

Complete guide to designing consistent brand identities including business cards, letterhead, stationery, and brand style guides.

## Brand Identity Components (品牌识别组件)

### Core Elements

**Logo/Mark:**
- Primary logo (full color)
- Logo variations (reversed, single color)
- Clear space requirements
- Minimum size specifications

**Color Palette:**
- Primary colors (1-3 colors)
- Secondary colors (2-4 colors)
- Neutral colors (grays, blacks)
- Color codes (CMYK, RGB, Hex, Pantone)

**Typography:**
- Primary font family
- Secondary font family
- Font weights and styles
- Type hierarchy

### Applications

**Print Materials:**
- Business cards
- Letterhead/envelopes
- Notepads
- Folders
- Labels/stickers
- Signage

**Digital:**
- Website
- Email templates
- Social media
- Presentations

## Business Cards (名片)

### Standard Sizes

**Common Business Card Sizes:**

| Size | Dimensions | Use Case | Region |
|------|------------|----------|--------|
| **Standard** | 3.5 × 2" (89 × 51mm) | US | United States |
| **European** | 85 × 55 mm | International | Europe, Asia |
| **Square** | 65 × 65 mm | Modern | Worldwide |
| **Slim** | 90 × 50 mm | Minimal | Modern |
| **Oval** | 90 × 55 mm | Distinctive | Less common |

### Card Layout

**Standard Layout (Landscape):**

```
┌────────────────────┐
│ [Logo]   [Name]   │  ← Top 10-15mm
│          [Title]   │
├────────────────────┤
│ [Contact Info]      │  ← Middle 50-60%
│ • Phone            │
│ • Email            │
│ • Website          │
│ • Address          │
└────────────────────┘

Typography:
- Name: 10-14pt
- Title: 8-10pt
- Contact: 6-8pt
```

**Alternative Layouts:**

```
Centered layout:
┌────────────────────┐
│      [Logo]        │
│                     │
│     [Name]         │
│    [Title]         │
│                     │
│  [Contact Info]     │
│  (centered)         │
└────────────────────┘

Horizontal layout:
┌────────────────────┐
│ [Logo] [Name] Title │
│                    │
│ [Contact Info]      │
└────────────────────┘
```

### Card Content

**Essential Information:**

```
Must include:
✓ Name
✓ Title/Position
✓ Contact method (at least one)

Should include:
✓ Company/organization
✓ Email
✓ Phone/mobile
✓ Website
✓ Address (if physical location)

May include:
✓ Social media handles
✓ Photo (for personal branding)
✓ QR code
```

### Card Stock and Finish

**Paper Options:**

| Stock | Weight | Thickness | Finish | Use Case |
|-------|--------|----------|--------|----------|
| **Standard** | 300-350gsm | 0.36mm | Gloss/Matte | Standard cards |
| **Premium** | 400gsm+ | 0.46mm+ | Matte/Textured | Luxury feel |
| **Recycled** | 300-350gsm | 0.36mm | Kraft/natural | Eco-friendly |
| **Plastic** | Clear/White | 0.76mm | Durable | Weatherproof |

**Finishes:**
- Matte: Non-reflective, writable
- Gloss: Shiny, vibrant
- UV coating: Extra durability
- Spot UV: Glossy highlights on matte
- Foil stamping: Metallic accents
- Embossing: Texture and dimension

## Letterhead and Envelopes (信纸和信封)

### Letterhead Design

**Standard Layout:**

```
┌─────────────────────────┐
│  [Logo]  [Company Name]  │  ← Header 20-25mm
├─────────────────────────┤
│                         │
│  [Body text area]       │  ← Content area
│  (margins for text)     │
│                         │
│                         │
│                         │
├─────────────────────────┤
│  [Footer]               │  ← Bottom 15-20mm
│  [Contact info]          │
└─────────────────────────┘

Letterhead size:
- US Letter: 8.5 × 11" (216 × 279mm)
- A4: 210 × 297mm
- Custom sizes available

Margins:
- Top: 20-25mm
- Sides: 20-25mm
- Bottom: 15-20mm
```

### Envelopes

**Standard Envelope Sizes:**

| Size | Dimensions | Encloses | Use Case |
|------|------------|----------|----------|
| **#10** | 4.125 × 9.5" | 3.5 × 8.5" (folded) | Standard (US) |
| **#9** | 3.875 × 8.875" | 3.5 × 8.5" (folded) | Standard (US) |
| **C5** | 162 × 229 mm | A5 (folded) | International |
| **C4** | 229 × 324 mm | A4 (folded) | International |

**Envelope Design:**

```
Front:
┌─────────────────────────┐
│  [Logo]  [Return Address] │  ← Top left
│                         │
│  [Recipient Address]    │  ← Center/lower left
│  [Name]                 │
│  [Street]               │

Window envelopes:
- Rectangle window: 1 × 2.5" (25 × 63mm)
```

## Logo Usage (Logo使用)

### Logo Clear Space

**Maintaining Logo Integrity:**

```
Clear space requirement:
- X = height of logo mark
- Maintain X space around all sides

┌─────────────────┐
│  XXXXXXXXXX     │  ← Clear space buffer
│  XX[Logo]XX     │
│  XXXXXXXXXX     │
└─────────────────┘

Never:
- Place elements too close
- Stretch or distort
- Rotate (unless specified)
- Alter colors (use approved versions)
```

### Logo Variations

**When to Use Variations:**

```
Full color logo:
- White/light backgrounds
- Printed materials
- Digital use
- Primary logo

Reversed logo:
- Dark backgrounds
- Photos, dark colors
- Contrast needed

Single color logo:
- Faxed documents
- Black & white copies
- Limited color printing
- Secondary applications
```

## Typography for Branding (品牌字体)

### Font Selection

**Brand Font Hierarchy:**

```
Primary font:
- Headlines, titles
- Logo wordmark
- Short copy
- Personality: Bold, distinctive

Secondary font:
- Body text, paragraphs
- Longer copy
- Personality: Readable, neutral

Accent font:
- Call-to-action
- Emphasis
- Personality: Decorative, script
- Use sparingly
```

**Font Pairing:**

```
Corporate: Sans-serif + Sans-serif
- Primary: Inter, Roboto, Open Sans
- Secondary: Source Sans, Helvetica
- Clean, modern

Professional: Serif + Sans-serif
- Primary: Garamond, Georgia
- Secondary: Helvetica, Open Sans
- Traditional, trustworthy

Modern: Display + Sans-serif
- Primary: Montserrat, Raleway
- Secondary: Source Sans, Open Sans
- Friendly, approachable

Limit to 2-3 font families
```

## Color Systems (色彩系统)

### Developing Color Palette

**Brand Color Structure:**

```
Primary colors (1-3):
- Main brand colors
- Used for logo, key elements
- High recognition

Secondary colors (2-4):
- Supporting colors
- Used for accents, sections
- Visual variety

Neutral colors (3-5):
- Grays, blacks, whites
- Used for backgrounds, text
- Foundation of palette

Accent colors (1-2):
- Highlights, CTAs
- Used sparingly for emphasis
```

**Color Specifications:**

```
For each color, define:
- CMYK values (print)
- RGB values (digital)
- Hex code (web)
- Pantone spot color (if needed)

Example primary blue:
- CMYK: C100 M70 Y0 K10
- RGB: R0 G77 B156
- Hex: #004D9C
- Pantone: PMS 2945 C
```

## Production Specifications (制作规范)

### File Preparation

**Resolution:**
- 300 DPI at final size
- Vector logos preferred
- Images: 300 DPI minimum

**Color Mode:**
- CMYK for print
- Spot colors for logos
- Use color profile: FOGRA39/51

**File Format:**
- PDF/X-4 preferred
- Include bleeds and crop marks

### Bleed and Safe Zones

**Business Cards:**
- Bleed: 3mm all sides
- Safe zone: 3mm from trim
- Text: 3mm from edges

**Letterhead:**
- Bleed: 3mm all sides
- Safe zone: 10mm from trim
- Text: 10mm from edges

**Envelopes:**
- Bleed: 3mm all sides (if printed)
- Window: Consider window placement

### Paper Selection

**Business Card Papers:**

| Paper | Weight | Thickness | Finish | Use Case |
|-------|--------|----------|--------|----------|
| **Cover** | 300gsm | 0.36mm | Gloss/Matte | Standard |

| **Extra thick** | 400gsm+ | 0.53mm+ | Various | Luxury |
| **Recycled** | 300gsm | 0.36mm | Kraft/natural | Eco |

**Letterhead Papers:**

## Consistency Principles (一致性原则)

### Visual Consistency

**Maintaining Consistency:**

```
Across all applications:
- Logo: Same size, placement
- Colors: Exact values specified
- Fonts: Same families, weights
- Spacing: Same proportions
- Alignment: Grid-based layouts

Checklist:
- ✓ Logo size consistent
- ✓ Colors match specification
- ✓ Fonts match selection
- ✓ Margins and spacing consistent
- ✓ Tone of voice matches brand
```

### Usage Guidelines

**Do's:**

```
✓ Follow brand guide
✓ Use approved logo versions
✓ Use exact color values
✓ Maintain clear space
✓ Keep typography consistent
✓ Test proofs before printing
✓ Update brand guide as needed
```

**Don'ts:**

```
✗ Stretch or distort logo
✗ Change colors arbitrarily
✗ Use unapproved fonts
✗ Place logo too close to edges
✗ Rotate or flip logo
✗ Use low-resolution logos
✗ Go off-brand style
```
