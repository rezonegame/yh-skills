# 真实证据锚点（写作前置模式）

> 来源：数字生命卡兹克「活人感写作」方法论拆解（2026-08-07 文章）
> 原文核心洞见：**活人感应该在写之前就锁定，不是写完再拿砂纸磨。** 砍词只解决"干净"，解决不了"空"。读者要的是"你经历过"，不是"你词干净"。
> 本文件是 yh-humanizer 的**生成前置**模块，与 SKILL.md 主流程（事后改写）互补：主流程治"已生成的AI味"，本模块治"从一开始就别生成AI味"。

## 为什么需要它

AI 最假的不是词，是它从没真的经历过任何事。让它写细节，它不敢给具体的（怕错），于是全用泛化描述：「时间流逝」「令人振奋」「为用户提供价值」。没有具体证据，就只能堆形容词。

事后润色（砍词、调节奏）能消除"模式化痕迹"，但消除不了"假均衡"——底层还是 AI 的均匀分布。**真正的人味靠证据，不靠词干净。**

## 核心机制：写作前强制填证据钩子

写任何有人味的文字之前，先填满证据锚点（**至少 3 个，缺一个就停笔去补**）。证据不是"润色素材"，是写作的**原料**——没有证据就不该开始写。

### 五类证据锚点（必填 ≥3）

| 锚点 | 要什么 | 示例 |
|------|--------|------|
| **时间** | 具体时刻，不是"最近/曾经" | 「上周三凌晨」「2023年那场雨」 |
| **地点/场景** | 具体到能看见，不是"某地" | 「出租屋书桌前」「菜市场三号摊位」 |
| **数字/代价** | 可量化，不是"很多/很久" | 「改了 7 版，熬到四点」「第一版发出去 0 转发」 |
| **失败经历** | 真被刺到过，不是"遇到挑战" | 「有客户当场把方案摔回桌面」 |
| **原话/对话** | 有引号的原话，不是转述 | 「我朋友甩来一句：你这写得像说明书」 |

### 反面 vs 正面（同一件事）

**无锚点（AI 味）**：
> 坚持创作需要毅力和方法，许多成功者都经历了漫长的积累期。

**有锚点（人话）**：
> 我那篇写了 7 版，熬到四点。发出去 0 转发。朋友甩来一句：你这写得像说明书。我当场把"毅力与方法"那段全删了。

差别不在词，在**有没有具体的人站在具体的位置付过代价**。

## 写作前置流程（生成前跑）

1. **列证据**：按五类锚点收集 ≥3 个真实细节（时间/场景/数字代价/失败经历/原话）。若写作者没有真实经历，**明确标注"虚构证据"或改用借位视角**，绝不默认生成编造的"亲历感"——这是事实性红线（见下）。
2. **锁人设**：一句话锁定身份 + 说话方式 + 禁忌（如"写了 8 年公众号、被删过 3 次号的老编辑，说话直接不装，不喊口号"）。
3. **套语气开关**：第一人称「我/咱们」，禁「笔者/用户」；允许不确定（「大概/可能/说不准」）；允许吐槽和主观偏向；必须出现 ≥2 个具体物（带温度/颜色/动作）。
4. **按节奏规则写**：连续不超过 3 个 >25 字长句；每 100 字至少 1 个 <8 字短句；问句占 5%–10%。
5. **成稿自检**（生成时带规则，不是事后救火）：扫禁用词命中数 → 算句长标准差 → 查证据锚点是否真实落地为具体细节。超阈值就重写。

## 事实性红线（不可违反）

1. **严禁编造亲历感。** 证据锚点是给"真实素材"用的模板，不是让 AI 编造经历的许可证。写作主体没有真实经历时，要么用"转述/研究/他人视角"（有出处），要么明示为虚构，绝不默认生成"我亲历过"的假细节。
2. **保持既有事实不变量。** 姓名、数字、引用、来源、第一人称边界在锚点填完后不得漂移（与 voice-profiles 的事实性不变量一致）。
3. **不替代 yh-humanizer 主流程。** 本模块产出后仍可过一遍 SKILL.md 的 36 模式扫描与反 AI 自审，但优先把证据前置，减少事后补。

## 与三轴终审判据的关系

- 证据锚点（时间/代价/原话）→ 直接喂满**代价轴**（付过代价的痕迹）和**位置轴**（具体的人站在具体位置）。
- 人设锁定 → 防止**手迹轴**被"统一的伪人味"洗平（通篇一个调的调教味）。
- 本模块是**输入侧**，三轴是**输出侧质检**；两者配套：写作前置填证据 → 成稿用三轴验人味是否落地。

## 平台适配（可选升级）

公众号长文 / 小红书种草 / 视频口播稿 / 带货文案，各自在母版上加一层场景参数：
- 公众号：开头用钩子别用定义；每段 ≤5 行；结尾给真实小故事收。
- 小红书：口语化、emoji 不堆；第一句抛痛点；结尾抛互动问句。
- 口播稿：写成"说"的不是"读"的；用「（停）」标停顿；一句一个信息点。
- 带货：用"我自己先踩/先用"的真实姿态；给具体使用场景；不喊"卓越/极致"。
